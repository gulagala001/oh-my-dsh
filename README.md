## 设计范围

- 单一主模型、统一提示词、自然语言回复和原生工具调用。
- 按实际需要接入画布上下文、工作笔记、长期记忆与原文回捞。
- 简洁的对话 UI；需要时再呈现任务与记忆。
- 不保留多魂、投票、交稿封皮、动作转译和专属内部工具循环。
- 不添加安全门、审批流、强制验证或其他非核心功能。

先打通最小执行循环，再接入上下文与记忆，最后围绕真实功能构建 UI。只迁入需要的实现，不先搬整套旧架构再删。
