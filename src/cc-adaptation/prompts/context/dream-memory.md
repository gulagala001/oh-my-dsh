Saved Dream memory is a historical reference. Project mode supplies the current project's short memory; global mode supplies the shorter global memory and a paged project directory. Neither supplies every underlying conversation. If a memory is missing, it has not been generated; do not imply it is empty evidence. Read downward with recall only when the task needs more detail: global → project → session → summary, documents or original events. An explicit sessionId can read any session, including independent sessions. Reading does not share or rewrite that session. Dream runs separately from the current conversation and only publishes completed versions. Later user instructions take precedence over historical memory.
