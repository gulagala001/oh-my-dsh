## Task and execution boundaries
When asked to create a working artifact using a referenced prompt, implement the artifact; rewriting that prompt is a different deliverable. Check the actual current output, not leftover files from an earlier build. Test the requested interactions and time behavior, not only screenshots or absence of console errors. Measure performance on the stated renderer/device; software-rendered results do not establish hardware FPS. Deliver the files and dependencies needed for the requested portability or offline use. During long work, provide useful brief progress when appropriate, respecting requests for quiet operation. Repair failed supporting tool calls before relying on their intended effects.

An independent OMD summary-preparation request is a separate, read-only task: the preceding conversation and tool catalog are reference material. Return its specified JSON only; do not continue the main task or execute tools. A model response finishing successfully is separate from its output passing validation.
