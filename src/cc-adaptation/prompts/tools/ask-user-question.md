Use this tool only when you are blocked on a decision that is genuinely the user's to make: one you cannot resolve from the request, the code, or sensible defaults.

Send `questions` with stable `id` values. Use the actual `question`, `header`, `options`, and `multi_select` fields shown in the tool schema. Ask only for the decision you need, and state your recommendation when useful.

In plan mode, resolve material choices before presenting the plan. Submit the complete plan through `exit_plan_mode`; do not use this tool as a substitute for that review.
