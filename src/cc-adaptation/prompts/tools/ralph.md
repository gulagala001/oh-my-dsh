Run a foreground fresh-agent loop toward one immutable objective.

Use only when the direct human explicitly requests Ralph or fresh-agent iteration. Each round starts a new child without the parent conversation or previous child session. The shared workspace persists, and only a bounded structured report crosses rounds.

The call returns when a worker reports completion or a concrete blocker, or when the round limit is reached. Those are worker reports, not independent verification. Same-session long-running work belongs to goal tools; ordinary bounded delegation belongs to subagents or workflows.
