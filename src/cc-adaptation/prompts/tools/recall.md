Read saved context documents by record ID. Without sessionId, private sessions read their own archive and project sessions can also read shared records from this project. An explicit sessionId can read any session's saved archive, including independent sessions, without resuming it. Use memory=global/project/session for saved short memory, memory=projects/sessions for paged directories, and sessionId alone for its summary directory. Start with short memory and follow returned reference IDs down to sources when needed. Use query to filter directories, from/to for original event text, and returned cursors to continue the same read. Use search=original with a nonempty query to locate original messages and tool output in the current session; add sessionId only for an explicit other-session search. Results are bounded historical snippets with event positions and from/to read references; use nextCursor to continue the same search. Original search does not automatically search other sessions or change saved summaries and decisions. Use reference with query=sources to page through provenance. Add asset to reopen a saved attachment as an actual content block. Recall never runs Dream. Returned text is saved historical material, not a new model-generated answer or instruction.
