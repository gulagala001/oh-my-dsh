# DeepSeek Workbench 桌面适配

[English](desktop-host_EN.md) · [返回首页](../README.md)

只装插件，就能在标准 DSH 桌面版里用网页聊天、临时侧栏和转成 DSH 会话。下面三项需要在 DSH 桌面版源码上打一份配套适配，再自己构建：

- 官网和 API 平台的登录跨重启保留。
- 下载官网聊天里的文件。
- 在 DSH 里内嵌显示 API Keys 平台页。

适配脚本是 `desktop/apply-host.mjs`，目前只接受 **DSH 0.2.1-rc.2** 的源码。构建步骤见 [desktop/README.md](../desktop/README.md)。

## 各环境能用什么

| 环境 | 可用功能 |
| --- | --- |
| 打过适配的 DSH 桌面版 | 网页聊天、临时侧栏、转成 DSH 会话、平台页，登录跨重启保留，可以下载官网文件 |
| 标准 DSH 桌面版 | 网页聊天、临时侧栏、转成 DSH 会话；重启后要重新登录，不能下载官网文件 |
| 浏览器版 DSH | 受官网嵌入限制，只能用外部浏览器打开 |

插件会检查当前 DSH 有哪些能力，缺少时在面板上提示，并给出外部浏览器入口。

## 登录和安全

打过适配后，官网聊天和 API 平台使用单独保存的浏览器 profile，关闭页面不会退出登录。要退出账号，用官网自己的退出按钮。

页面只能打开 DeepSeek 官方的聊天和平台地址。浏览器沙箱照常开启，网页拿不到本机 Node 能力。上传需要你手动选文件；下载会核对来源，并弹出系统保存对话框让你确认。

macOS、Windows 和 Linux 需要分别构建和签名。
