# 桌面宿主

[English](desktop-host_EN.md) · [首页](../README.md)

本版精确适配 **DSH 0.2.1-rc.2**，框架为 **Cordis 4.0.5**。插件包与桌面宿主 bridge 分别承担界面和 Electron 能力；完整内嵌体验需要同时具备两者。

## 必要能力

宿主必须提供 `window.dshDesktop.browser`，包含隔离页面的获取与释放接口；标准 rc.2 桌面已提供这组接口及页面读取。持久 profile、受约束的官网下载与扩展平台页面由配套源码适配提供。插件会检查实际能力；缺少时显示能力不可用，并提供外部浏览器入口。API 平台的当前账号授权还需要宿主的 `window.dshPlatform` 接口。

标准 DSH 仅安装插件包不会修改 Electron 主进程、preload 或已签名应用。自定义桌面发行方需在自己拥有的 DSH rc.2 源码副本中应用匹配适配，完整重建受影响的 Host、Client、Web、桌面主进程及 preload，并按上游平台流程打包和签名。源码适配入口为 `desktop/apply-host.mjs`；它会校验真实源码与定位条件，拒绝不匹配的输入。

## 会话与安全边界

安装配套适配后，官网聊天和 API 平台使用宿主管理的持久 Chromium profile；释放页面不会清空登录。账号退出通过官网自己的退出入口完成。

导航限制为 DeepSeek 官方聊天与平台页面。登录验证码等必要资源由明确的宿主策略控制；页面继续启用 Chromium 沙箱、web security 与 context isolation，并关闭 Node integration。上传使用手动文件选择器；下载经过来源和重定向校验，并由原生保存对话框确认。

临时聊天清理通过当前官网会话执行，关闭时等待删除完成。普通页面释放只释放浏览器资源，普通聊天仍保留官网历史。

## 兼容范围

| 环境 | 本版行为 |
| --- | --- |
| DSH rc.2 桌面 + 配套 bridge | 提供内嵌聊天、临时侧栏、网页迁移和平台入口 |
| 标准 DSH rc.2 桌面 | 内嵌聊天、临时侧栏和网页迁移；登录使用进程内分区，官网下载不可用 |
| DSH rc.2 浏览器界面 | 受官网嵌入与跨域限制，提供外部入口 |

macOS、Windows 和 Linux 的桌面发行需分别完成匹配的宿主构建与平台验证。本项目不把单一平台或隔离检查视作全部平台的实机验证。
