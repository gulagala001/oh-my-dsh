# DeepSeek Workbench 桌面使用说明

[English](desktop-host_EN.md) · [返回首页](../README.md)

在 DSH 桌面版安装并启用插件，打开网页聊天或临时侧栏。首次使用时登录官网，之后用同一个桌面资料打开即可继续。

## 各环境能用什么

| 入口 | 使用方法 |
| --- | --- |
| 桌面网页聊天 | 可在插件浏览器里继续聊天、下载官网文件，或选 **在 DSH 中继续**。 |
| 基础网页视图 | 插件浏览器无法启动时会显示原因。基础视图的登录保留和下载能力取决于当前宿主。 |
| API 开放平台 | 在 **设置 → 账号** 打开。支持内嵌 API Keys 页的宿主会直接显示页面，其他宿主可在外部浏览器打开。 |
| 网页版 DSH | 在外部浏览器打开官网。 |

## 登录和安全

官网聊天与 API 平台分别登录。要退出账号，请使用对应官网的退出按钮。保存下载文件时可选择目标位置。
