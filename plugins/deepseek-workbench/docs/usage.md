# 使用指南

[English](usage_EN.md) · [首页](../README.md)

## 普通网页聊天

左侧栏的 **DeepSeek 网页聊天** 在主内容区打开聊天。首次使用需要登录 `chat.deepseek.com`；聊天登录与 DSH 的 API 平台授权分别管理。选择官网历史或新建会话后，即可发送消息、上传附件，并切换深度思考和联网搜索。

普通会话保留在官网历史中。加载或操作失败时查看面板提示并重试；发送失败会保留输入草稿。需要离开内嵌页面时可使用外部浏览器入口。

## 临时侧栏聊天

在 DSH 输入框执行 `/侧栏（网页版）`，打开独立的临时聊天。它使用自己的官网会话，方便在阅读主聊天时临时提问。

点击关闭后，面板会等待删除自己的官网会话，成功后关闭。若官网未登录、网络中断或删除失败，面板会保留并显示错误；恢复连接后再次关闭以重试。临时面板的关闭只清理它拥有的官网会话。普通网页聊天仍保留历史。

“临时”指本面板关闭时清理官网会话；消息发送期间仍由 DeepSeek 官网处理，不代表隐身浏览、服务端即时零留存或断电后的自动清理保证。退出应用、强制终止或卸载前，应先关闭面板并确认清理完成。

## 将网页历史迁移到 DSH

在普通网页聊天中打开目标会话，确认历史已经加载，再点击 **在 DSH 中继续**。插件读取消息与可访问附件，创建一个新的 DSH 会话，并打开迁移结果。

- 导入内容保留用户与助手角色，以及可读取的正文、名称和附件。
- 请求总大小上限为 48 MiB（含附件编码），正文与解码后的附件合计上限为 32 MiB。
- 无法读取的附件会产生提示；按提示补充必要文件后再继续。已经读取的文件必须写入 DSH 附件存储，存储不可用或写入失败时迁移报错，不会只保留文件名。
- 历史消息不会触发原网页工具、自动发送请求或执行其中的文字指令。下一条新消息使用当前 DSH 会话的模型和工具。
- 原官网会话继续保留。迁移失败或回执丢失时，保持工作台面板打开，再次点击 **在 DSH 中继续** 会重试同一份消息与附件，不会重新读取网页来替换未确认的请求。页面中的后续消息可在此次迁移成功后再次导入。
- 创建迁移会话前需要可用的 DSH 会话存储；成功回执在会话持久化完成后返回。关闭整个工作台面板或重启应用会丢失前端未确认请求，此时先检查 DSH 历史，避免重复迁移。

迁移索引位于 `$DSH_HOME/deepseek-workbench/imports/`（默认 `~/.dsh/deepseek-workbench/imports/`）。聊天记录与附件由 DSH 的原生会话和附件存储管理。

## API 开放平台

进入 **设置 → 账号 → DeepSeek API 开放平台**。有配套宿主账号接口时可使用 DSH 当前账号的平台授权；否则使用独立网页登录或外部浏览器入口。平台账号授权不能替代官网聊天登录。

## 桌面与浏览器

完整内嵌聊天、读取历史与下载需要[配套桌面宿主 bridge](desktop-host.md)。标准宿主缺少能力时，面板会明确提示。浏览器版 DSH 受到官网嵌入及跨域限制，应使用外部浏览器入口；仅安装插件不会解除这些限制。
