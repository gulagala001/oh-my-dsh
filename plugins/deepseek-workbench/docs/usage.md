# DeepSeek Workbench 用法

[English](usage_EN.md) · [返回首页](../README.md)

## 网页聊天

点左侧栏 **插件** 上方的 **DeepSeek 网页聊天**，会在主界面打开官网聊天。第一次用要登录 `chat.deepseek.com`，这个账号和 DSH 里的 API 平台账号分开。选一条官网历史或新建聊天后，就能发消息、传附件，切换深度思考和联网搜索。

普通聊天会留在官网历史里。加载或操作失败时看面板上的提示再重试；发送失败时输入的内容会保留。想离开内嵌页面，可以用外部浏览器打开。

## 临时侧栏

在 DSH 输入框里输入 `/侧栏（网页版）`，会打开一个独立的临时聊天，方便边看主聊天边问。

点关闭时，面板会先删掉这条官网会话，删完才关。如果没登录、断网或删除失败，面板会留着并显示错误，网络恢复后再点一次关闭。普通网页聊天的历史不受影响。

"临时"的意思是关闭面板时删掉这条官网会话。聊天过程中消息仍由 DeepSeek 官网处理，它不是无痕模式。退出 DSH、强制关闭或卸载插件前，先关掉临时侧栏并确认已清理。

## 转成 DSH 会话

在网页聊天里打开要转的那条聊天，等历史加载完，点 **在 DSH 中继续**。插件会读取消息和能访问的附件，新建一个 DSH 会话并打开它。

- 转过来的内容保留用户和助手的角色，以及能读到的正文、文件名和附件。
- 单次最多 48 MiB（包括附件编码后的大小），正文加附件解码后最多 32 MiB。
- 读不到的附件会提示你，按提示补上需要的文件后再继续。已经读到的文件会存进 DSH 的附件存储；存储出错时整次转换报错，不会只留下文件名。
- 网页里的工具调用和文字指令不会被重新执行，也不会自动发送消息。下一条消息用当前 DSH 会话的模型和工具。
- 原来的官网聊天还在。转换失败时别关面板，再点一次 **在 DSH 中继续** 会重试同一批内容。之后网页里新增的消息，可以等这次成功后再转一次。
- 如果转换途中关掉了整个面板或重启了 DSH，先去 DSH 的历史里看看会话是否已经建好，避免重复转换。

转换索引存在 `$DSH_HOME/deepseek-workbench/imports/`（默认 `~/.dsh/deepseek-workbench/imports/`）。聊天记录和附件由 DSH 自己保存。

## API 开放平台

打开 **设置 → 账号 → DeepSeek API 开放平台**。如果你的 DSH 支持，会直接沿用当前 DSH 账号的平台登录；否则需要单独登录网页，或用外部浏览器打开。平台账号不能代替官网聊天登录。

## 桌面版和浏览器版

内嵌聊天需要 DSH 桌面版。登录跨重启保留和下载官网文件需要[桌面适配](desktop-host.md)，缺少这些能力时面板会提示。浏览器版 DSH 受官网的嵌入限制，只能用外部浏览器打开。
