# Changelog

## 0.1.0-dsh.0.2.1-rc.2

- Skills, MCP, Instructions, Commands and Hooks tabs on the DSH Plugins page.
- Skill invocation switches through native frontmatter; create, import, edit and delete skills.
- MCP servers from `mcp.json` with per-tool switches, JSON import and reconnect; profile servers can be switched.
- Personal and project AGENTS.md / CLAUDE.md management.
- Custom `/commands` from Markdown prompt templates.
- Claude Code compatible command hooks for six session and tool events, with test runs.
- Exact DSH 0.2.1-rc.2 / Cordis 4.0.5 compatibility.
