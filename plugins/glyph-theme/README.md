# Glyph · 动态字符

适配 **DSH 0.2.1-rc.2** 的动态字符主题。深黑与亮白构成鲜明层次，立体的 DeepSeek 字符鲸鱼具有体积、明暗和独立的尾鳍动作，镜头以四段分镜围绕它转动，通过局部轮廓匹配和曲线遮挡衔接全身、头部与尾鳍特写。鲸鱼、流动背景与波纹共用同一字符网格，鼠标移动只扰动附近的字符；点击背景会产生相互增强、抵消的传播波纹。边界、图标、菜单、表单与开关均以字符呈现。打开思考强度面板并选到最高档时，DeepSeek 蓝色宽波持续从滑块向外扩散，波峰与波谷带动字符表面起伏；新任务与已有对话均生效，关闭面板后自然淡出。动态效果避开正文与输入区域。

## 独立安装

在 DSH 的插件管理中安装 `dsh-glyph-theme-1.0.0-dsh.0.2.1-rc.2.tgz`，或使用匹配宿主的 CLI：

```sh
dsh plugin --profile YOUR_PROFILE add /absolute/path/dsh-glyph-theme-1.0.0-dsh.0.2.1-rc.2.tgz
```

按宿主提示重载插件。安装后默认启用；“设置 → Glyph 字符主题”可关闭或降低动态效果。明暗模式使用 DSH 的通用设置。其他宿主版本未经适配，不混装。

## 显示与交互

主题设置只存当前浏览器。字符图标随原生控件同步滚动；消息正文、气泡和输入区使用实色阅读底，背景动效避开内容区域。思考强度各档均有字符动效：轨道字符流动起伏、档位明暗变化、滑块边缘循环流光与中心呼吸；最高档使用 DeepSeek 蓝色并联动背景波浪。HTML iframe、图片、视频、PDF 和代码编辑器内容保持原始渲染；外层导航与控件使用字符。静态文本保持选择、复制、中文输入与原生无障碍语义。系统减少动态效果和主题开关均可停止持续动画。

## 源码构建

在源码工作区运行 `node scripts/build-glyph-theme.mjs`，再执行 `npm pack ./plugins/glyph-theme` 生成安装包。

本包为本地可安装发行工件；市场收录与在线发布以正式发布页面为准。
