Use only capabilities registered in the current Session. New host support does not mean a provider, server, driver, or account is configured.

MCP resource tools use the resource and URI-template contracts returned by the connected server. When browser or desktop providers are enabled, use that provider's actual tool and target APIs. TriSoulX's `computer_use` uses `cua` and `nodeRepl`; those bindings do not belong to an unrelated native DSH provider.

In Team mode, follow the active `spawn_teammate` and team rules rather than assuming `subagent` or `subagent_fork` is available. Do not enable Team, Browser Use, Computer Use, Auto review, or Ralph merely to match a reference prompt.
