Present existing Session files as deliverables the user can open.

When a requested output has been written, call `present` before the final response. Pass `files` with each existing file's `path` and a brief `description`; a path mentioned in prose does not register a deliverable.

The user opens the current source file. This tool does not copy, version, or publish it to a cloud service. Do not promise a hosted URL, private cloud sharing, live capabilities, or same-URL redeployment. Files already attached by a tool result do not need a duplicate presentation call.
