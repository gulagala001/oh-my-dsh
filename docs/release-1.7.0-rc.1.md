# Oh My DSH 1.7.0-rc.1 预发布版

适配 DSH 0.1.7-alpha.1，内置 OpenCU 1.1.0-rc.1。保持插件、预设和数据目录的兼容标识。

## 更新内容

- 融合 DSH 0.1.7-alpha.1 的原生工作过程、设置、预设和 V4 会话，保留 OMD 上下文、任务验证、BT、预算和 PTC。
- 工具全部结束后立即显示完成汇总，不再等待模型回复结束；保留展开详情和失败/停止状态。
- 四套皮肤适配新版布局、设置、明暗和窄屏；子路径部署与提示词优化同步适配。
- 旧会话迁移保留原日志并重映射关联记录，支持中断恢复；修复旧多区间压缩、回合归属和系统头顺序。旧索引未落盘时保留材料并停用失效索引，原索引保存在迁移日志。
- 后台任务保留软让出、原始硬超时和插话唤醒；修复电脑工具重置、共同安装和旧依赖缓存问题。
- 本版为预发布；Windows 原生桌面及缩放档位本轮尚未真机复验。

## 安装与升级

先停止旧宿主，完整备份 DSH_HOME；将宿主更新至 DSH 0.1.7-alpha.1，再安装：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v1.7.0-rc.1
```

自定义 profile 将 `web` 替换成原名称。插件不自动升级全局 DSH。旧宿主 DSH 0.1.6-alpha.2 请继续使用 OMD 1.6.1。

首次启动会生成 V4 会话并重映射上下文引用，原日志不覆盖，迁移日志保留关联记录的原始副本。回退时停止新宿主并恢复成套备份，不能只降级宿主后继续写同一个目录。旧配置导入后保留为 `settings.yaml.imported`。

整个插件启停会刷新浏览器，已保存文字草稿保留，未发送附件需重新添加；普通设置变更不刷新。

## 验证范围与限制

验证覆盖本地 333 个旧会话的严格迁移校验和原生恢复、新版压缩持久化、原版宿主安装、模式切换、后台/硬超时/PTC/插话、独立与共同安装、启停/卸载、四套皮肤明暗与窄屏、设置持久化、优化器及子路径。

Windows 原生桌面和各缩放档位本轮未真机复验；该版本标记为预发布，不替代 GitHub 的最新稳定版。发行资产不包含现用会话、凭据、本地交接记录或构建缓存。
