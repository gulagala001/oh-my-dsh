# 0.2.0-rc.2.omd.0.5.2：修复草稿恢复导致的会话空白

继续配对官方 DSH `0.2.0-rc.2`，SDK、内置组件和 OpenCU 快照保持不变。

部分较新前端保存的草稿是 `{text, references}` 对象。rc.2 的恢复入口只接受字符串，打开这些会话时可能触发 `text.replace is not a function`，使整个会话消息与轨迹区域变空。会话日志本身仍然存在。

- 在 rc.2 输入恢复入口兼容结构化草稿；空草稿与文本草稿均可恢复，合法引用重新显示为引用标签。
- 保存完整原缓存副本，不清空浏览器缓存，不改写会话日志；不识别的数据保留并显示恢复提示，不让历史消息区域崩溃。
- 维持原生的视图、输入、草稿镜像、会话切换及附件处理。
- 普通字符串草稿保持原流程；alpha.1 已原生支持结构化草稿，本补丁仅供 rc.2 使用。
- 不含本机实验架构。

原缓存副本按会话保存在浏览器本地 `omd.draft-recovery.v1.<sessionId>`，不会上传。仅保留数据，不自动覆盖用户随后编辑的草稿。

安装：`github:gulagala001/oh-my-dsh#v0.2.0-rc.2.omd.0.5.2`。已运行 0.5.1 的 rc.2 用户可在版本面板检查并安装更新，随后结束任务、完整重启应用与 Host。

验证：修复前已复现会话区域空白；打包后实际安装到 rc.2 宿主，空／文本／引用／异常草稿、刷新、历史消息与轨迹检查通过。原版安装、模式切换、启停卸载、附件和引用切换、原生实际自更新回归通过。此轮未重新实测 Windows 桌面。
