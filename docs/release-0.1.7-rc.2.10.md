# Oh My DSH 0.1.7-rc.2.10

正式版，适配 DSH 0.1.7-rc.2 Web 与官方桌面版，内置 OpenCU 1.1.6。

## 28 套独立配色

保留黑白灰、冰蓝、暖砂、晴空蓝四套经典配色，新增 24 套：

| 色系 | 新增配色 |
| --- | --- |
| 自然绿 | 薄荷、森林、抹茶、橄榄、翡翠、竹影 |
| 青蓝 | 青瓷、海盐、深海、靛青、极地 |
| 紫粉 | 薰衣草、葡萄、暮紫、丁香、樱花、玫瑰、莓果 |
| 暖色 | 珊瑚、落日、琥珀、奶咖 |
| 中性 | 石墨、羊皮纸 |

每套新增配色提供浅色与深色色板，涵盖背景、正文、辅助文字、代码、按钮和状态颜色，不只是更换强调色。选择器按色系分组并显示总数；不复制主题布局或字体。

旧配色、导入主题配色、明暗模式、背景和恢复默认行为保持兼容。不依赖第三方配色插件；本版继续包含 0.1.7-rc.2.9 的 Windows 兼容和推荐页面开关修复。

## 使用与升级

入口：**设置 → 外观 → 配色**。选择主题默认配色可恢复原来的颜色，不清除背景。

在当前 DSH profile 的插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.10`，或在 OMD 版本面板更新。安装后完整重启 DSH，确认当前版本为 0.1.7-rc.2.10。

详见 [主题、配色与背景说明](skins.md)。
