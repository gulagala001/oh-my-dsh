# Oh My DSH 0.1.7-rc.2.9

**正式修复版，适配 DSH 0.1.7-rc.2 Web 与官方桌面版，内置 OpenCU 1.1.6。**

## 变化

- 推荐插件页面默认显示；可在“设置 → Oh My DSH → 常用 → 显示推荐插件页面”关闭，保存后立即生效并持久化。仅隐藏页面，不卸载插件、不改变自动更新设置。
- 内置 OpenCU 1.1.6：以公开回调接口接收命令输出，兼容丢失 execFile 自定义 promisify 协议的控制台隐藏补丁，修复 Windows 桌面检查和 Chrome 注册表操作收到 undefined 的错误。
- 浏览器、桌面和 Chrome 状态查询独立处理失败，保留正常组件、具体错误和修复入口；不会因一个组件报错让整页显示错误状态。
- 保留主题、配色、背景、记忆、待办、附件和电脑操控设计；本次不实施模块化，也不修改 Logo 或标题行为。

## 升级

通过当前 profile 的插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.9`，或在 OMD 版本面板更新。任务结束后完整退出并重新打开 DSH；仅刷新页面不能换入后端。确认“当前版本”为 **0.1.7-rc.2.9**。

## 验证范围

回归覆盖控制台隐藏补丁的同类复现、实际子进程输出与错误语义、组件故障隔离，以及真实浏览器中的页面开关、保存失败保护和刷新持久化。使用正式桌面程序验证隔离安装、重启与会话/外观保留；结果见发布附件。Windows 专项与全量平台结果以对应提交的 Actions 为准，未实测环境不由 macOS 测试外推。
