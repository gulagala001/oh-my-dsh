# 0.2.0-rc.2.omd.0.6.1：无项目聊天与独立工作目录

本版配对官方 DSH `0.2.0-rc.2`，用于 **现有官方桌面，GitHub Latest 渠道**。OMD 版本由 `0.6.0` 升至 `0.6.1`；宿主、SDK 与内置 OpenCU `1.2.1` 保持原配对。

## 本版改动

- 新聊天不必先选择项目。已选工作区悬停时，点击右侧 **×** 取消选择；草稿、附件和所选模型保留，输入区可以继续编辑和发送。
- 首次发送才在运行 DSH 的电脑上创建 **文稿（Documents）/DSH/YYYY-MM-DD/首条消息名** 目录。名称保留中文，同名自动编号；未发送的新聊天不提前创建目录。
- 每段聊天持久绑定工作目录，重复发送、刷新、重启和继续聊天不重复创建；另开无项目聊天获得新的独立目录。
- 自动目录不加入已注册的工作区列表，聊天显示在现有 **未分组** 中。新聊天仍可选择已有工作区。

[无项目聊天使用方法](usage.md#无项目聊天)。

## 安装与升级

按实际宿主选择完整配对版本。升级前结束任务、停止服务或完整退出应用，并备份实际 `DSH_HOME`。自动工作目录位于 `DSH_HOME` 外，工作文件需另行备份。

安装来源：`github:gulagala001/oh-my-dsh#v0.2.0-rc.2.omd.0.6.1`。另一宿主见[对应发行说明](release-0.2.1-alpha.1.omd.0.6.1.md)，完整步骤见[安装与升级指南](upgrade.md)。
