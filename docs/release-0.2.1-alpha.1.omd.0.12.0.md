# OMD 0.2.1-alpha.1.omd.0.12.0（候选，未正式发布）

配对官方 DSH **0.2.1-alpha.1**，内置 **OpenCU 1.4.0**。两套构建保留各自 SDK、组件快照与依赖锁定。当前公开安装仍为对应宿主的 **0.10.0**；本候选没有新 tag／Release，只能按[本地候选验收](upgrade.md#candidate-install)安装对应包。0.11.0 的兼容交付与本次 0.12.0 均为本地未发布记录。

- [REA 开发调查](rea-development.md)固定 `rea-agents@6.1.0`，保存实际目标、完整版本、来源 commit、工件 SHA-256、命令、退出状态与执行时间；静态分析或 CLI 退出 0 不替代产品验收。
- Loader 在显式移除条目及其已有子条目退出期间临时标记运行条目，防止原生 bundle 重组将整份 effective patch 误写入用户 `cordis.yml`；原始 options 保持不变，失败也等待已有清理完成，用户明确发起的原生配置写入继续生效。
- 任务证据保存真实工具调用身份、实际命令、退出状态和起止时间，区分文字说明与执行结果，继续保留原始需求及证据回查。
- OpenCU 下载保存为持久文件附件，原生与 OMD-PTC 对话均可打开预览；重复保存复用交付，失败保留原因，停止及冷启动后仍可读取已保存附件。辅助预览在页面重载后恢复，缺失或失效缓存不拖住基础能力。
- iOS Liquid Glass 默认气泡与按钮提升文字对比度，自定义配色和用户文字色继续生效；版本排序、同版判断与重复迁移按固定身份核对。
- 推荐插件“无限四代”恢复入口并重新核验：固定 commit `5e377394fe9d6aeab6380e2a5a5f959bc1384426`，归档 SHA-256 `9e6d66001eb06fc790d6eae91d191175b53503521b7f4db8c92a061a111752b1`。上游仓库更名为五代只改变归档根目录名，28 个文件与 Git tree 精确匹配；两宿主原归档的原生安装、启停、重启与卸载已通过，不以新仓库名称替换四代身份。

- 推荐插件固定核验 Status `0.35.0`、Market `1.66.14`、Whale `0.3.18` 和 Blender `1.0.5`，下载校验已审阅发行包 SHA-256。Blender 提供固定 GitHub 安装入口；第三方真实账户、Blender 实际视口和生态业务服务未计为通过。

两宿主 Mac 隔离原生 Web 的下载交付、文件预览、PTC、停止／冷恢复以及默认与自定义配色专项已有真实执行证据。两宿主各八个真实会话基线、真实 Web 与有限探索已通过；推荐插件按原版宿主对照完成两种加载顺序及启停、重启、卸载。alpha.1 的 Turn Rewind 仍由原生宿主拒绝，与原版一致。当前候选的工件身份、完整来源和执行证据单独冻结记录，未将历史 CI 归给本候选。未宣称 Windows/Linux 本轮候选验证、真实账号、官方原生桌面 App 或桌面硬件流程通过。

原生宿主已知限制：两宿主原版 DSH 与固定 IUI、未安装 OMD／OMAA 的独立复现确认，卸载旧预设后 Web 复用旧空白会话的 `storedPreset` 会失败。默认仍为 `standard`，未指定旧 session id 的新标准会话可用；公开 select 冷激活失败，同 id 切 standard 冲突，宿主没有可等待完成的 pre-uninstall API。本候选不宣称缺失预设自动恢复通过，也不删除或迁移会话、草稿附件。其他卸载后的插件、设置与数据保留须按各自真实报告核对。新增保护的验收以最终工件身份及对应真实报告为准，较早专项结果不能替代。

```sh
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile candidate add file:/absolute/path/trisoul_x-0.2.1-alpha.1.omd.0.12.0.tgz
```
