# Oh My DSH 0.1.6

Oh My DSH 0.1.6 为正式版，兼容 DSH 0.1.6-alpha.2。包含四套完整主题、提示词优化、对话记录优化和上下文设置整理。插件版本与宿主版本分别标注。

## 提示词优化

- 输入框默认显示星星入口，支持轻润色、结构化、步骤规划，以及撤销、重做、恢复原稿和补充要求后的继续优化。
- 发送前自动轻润色默认关闭；点亮星星后复用当前模型，成功后交回宿主发送。每次优化会额外调用模型。
- 保留附件、结构化引用和排队／接管语义；取消、失败、超时、切换会话或编辑冲突时保留草稿。界面字体、圆角与强调色跟随主题。

## 界面与皮肤

- 设置新增外观页和四套从零制作的完整主题：Codex Desktop、iOS Liquid Glass、Claude CLI、Google Material Expressive。早期五套视觉皮肤及其专用字体资源已移除。
- 完整布局覆盖侧栏、对话、输入区、工作台、设置、明暗与窄屏。皮肤即时切换，可导入、降低效果和恢复默认；选择保存在当前浏览器。
- Codex Desktop 1.0.1 使用黑白强调、冷灰侧栏和悬浮工作台；顶栏贯通两列，右栏默认 360px，开关固定在窗口最右端。原生拖动保持有效，宽度偏好按皮肤保存。
- 过程记录、工具操作和上下文记录使用独立折叠入口，保留实际结果、文件操作、错误和原始记录。
- 历史加载数量支持 50、200、500 条，默认 200；影响初次加载与“加载更早”，不改变模型上下文或已展开的内容。

## 上下文与兼容

- 设置 API 与处理管线统一使用宿主配置约束，拒绝无效类型、未知和已退役字段。
- 压缩、替换与展示记录加入批次关联，便于正确显示同一次上下文操作。
- 移除已退役的旧自动记忆、状态提炼、探针和整理执行器，以及未装配的提示词副本；旧资料保留只读访问。
- 当前 ContextPipeline、用户原话与附件回查、Todo 与验证账本继续保留；未恢复旧自动记忆执行链。
- 同步 OpenCU 1.0.4 发行快照中的操作分组和界面修正，保留浏览器与桌面操控集成。

## 安装与升级

停止原服务，沿用原来的 `DSH_HOME`、profile、模型配置和凭据安装：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v0.1.6
```

自定义 profile 请将 `web` 替换成原名称。随后按原方式启动 DSH，刷新浏览器，在「设置 → 外观」选择皮肤。不会自动覆盖现有皮肤、模型或手工填写的全局背景。

发行资产包含可安装的 `.tgz`、含已构建界面的源码 ZIP 和 SHA-256 校验清单。本地会话数据、凭据、内部交接记录、测试截图及无关素材不进入发行包。

## 验证与边界

macOS 已执行原有完整回归，并对新增提示词优化、四套主题、旧主题回退与宿主恢复进行定向复验。覆盖真实安装包、预设共存与切换、重启与卸载、上下文回查、历史数量和浏览器操控；提示词优化覆盖自动发送、附件与引用、取消和编辑冲突。Codex 全屏切换只保留一个可访问的收起按钮，窄屏与拖动宽度恢复也已复验。

发行内容已检查，OpenCU 快照文件哈希匹配。Linux Node 22.19/24 与 Windows Node 24 的完整回归由候选版本 CI 执行，最终结果见对应 GitHub Release。

公开截图与实际宿主功能不同，皮肤保留 DSH 的真实入口，不提供 Codex、Claude 或 Google 的账号服务。系统字体在不同平台可能采用回退字体。Computer Use 的 Windows 原生与系统授权范围以已有文档和对应实测为准，本机浏览器回归不代表所有平台原生能力均已重新验收。
