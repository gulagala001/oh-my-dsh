# OMD 0.13.1 候选：非工作区 Chat 的 Dream 隔离修复

本候选未正式发布。安装配对及本地验收方式见[升级指南](upgrade.md#candidate-install)，已有前端与 OpenCU 改进见 [0.13.0 候选说明](release-0.2.1-alpha.2.omd.0.13.0.md)。

当前配对为 DSH **0.2.1-alpha.2**，内置 OpenCU 1.5.0；其他宿主使用对应 SDK 与快照的独立构建。

本次修复阻止非工作区 Chat 的自动文件目录进入 Dream 项目、全局或自动共享整理。按持久化目录分配记录识别归属，保留显式会话整理、原文回查以及真实工作区会话；旧作业、换目录的后代、改动默认保存目录和删除文件目录后的旧 Chat 仍遵守隔离。失效的旧共享摘要停止注入，健康共享来源重新整理，原始会话和不可变历史版本保留。

整套 OMD 默认部署包含与实际宿主及 SDK 配对的独立 Intelligent UI 插件；公开发行暂停与推荐页门禁保持原状。验证使用本地模型替身、隔离数据与实际宿主，结论绑定本次源码、发行包及报告，不代表真实模型质量或未测试平台。
