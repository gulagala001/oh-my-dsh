# OMD 0.2.1-alpha.2.omd.0.12.2（候选，未正式发布）

配对官方 DSH **0.2.1-alpha.2**，内置 **OpenCU 1.4.1**。这是 [0.12.1](release-0.2.1-alpha.2.omd.0.12.1.md) 的修复候选，保留该版 SDK、组件快照、原生 activation、工作流、PTC 及 Pro 推理规则。rc.2 与 alpha.1 使用各自对应 SDK 的独立构建，不能混装。

- 冷启动后，原生旧会话可能已显示内容，尚未在内存中激活代理。OMD 范围和状态接口现在通过公共只读 `sessionController.inspect` 核对会话，不将它误报为不存在；不为查询激活代理或创建新的 OMD 账本。
- 只读取已有范围与上下文存档。已有原生人类输入、已绑定上下文或只有历史 OMD 档案的会话继续锁定范围；保存前重新核对，防止读取请求体期间开始的会话被扩大范围。
- 范围读取失败时显示“范围暂不可读”，可点击重试；取得实际值前不显示猜测的默认范围。缺失、损坏和不可读的原生记录保留真实错误。

0.12.1 的五插件组合、两加载顺序、三宿主独立构建与 a1→a2 同目录升级有各自冻结工件及真实证据。0.12.2 的冷查询、错误恢复与完整会话回归正在执行，结论须绑定本版实际包，不能将旧版结果视为同一包通过。

本候选没有公开 tag 或下载资产，公开安装版本继续为对应宿主的 **0.10.0**。[本地候选安装](upgrade.md#candidate-install)。现有 rc.2 官方桌面保留对应 rc.2 宿主；截至 2026-10-10，官方 alpha.2 Release 尚无桌面安装资产。本轮未宣称其他操作系统、真实账号或桌面硬件流程通过。

```sh
npx --yes @deepseek-ai/dsh@0.2.1-alpha.2 plugin --profile candidate add file:/absolute/path/trisoul_x-0.2.1-alpha.2.omd.0.12.2.tgz
```
