# OMD 0.14.1 候选：直接打开浏览器与目标内容

本候选未公开发布，配对 DSH **0.2.1-alpha.2**、OpenCU **1.6.1**。rc.2 与 alpha.1 保留各自 SDK 和原生组件快照的独立构建。

开始页提供宿主原生 **浏览器** 入口，点击直接进入地址栏；文件、终端与四个 OMD 内容页继续使用原生标签。移除“应用预览”和 Computer Use 中转入口，左侧导航与对话布局保持现状。

CU 有实际网页或应用目标时直接打开目标画面，设置与操作记录从内容工具栏打开。无目标时不显示空白应用页、恢复按钮或设置面板；历史无目标 CU 标签迁到浏览器，未选中的旧标签保持原焦点。

宿主原生浏览器与 CU 的控制对象保持各自的生命周期。Web 原生浏览器使用宿主 iframe，遵守网站的嵌入限制；通过 `@Browser` 指定的 CU 网页仍使用实际受控浏览器。不会把原生 iframe 当作可由 CU 操控的页面。

本轮结论仅绑定实际代码、发行包和宿主流程，具体未测平台与桌面部署状态以交付记录为准。安装方式见[升级指南](upgrade.md#candidate-install)。
