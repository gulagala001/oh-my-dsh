# Oh My DSH 0.1.7-rc.2.11

正式版，适配 DSH 0.1.7-rc.2 Web 与官方桌面版，内置 OpenCU 1.1.6。

## 高级外观定制

新增 **设置 → 外观 → 高级设置**。支持浅深色分别定制页面和分区颜色、文字与交互颜色、字体与字号、行高、圆角、边框、面板模糊和阴影；未修改项继续跟随主题。支持单项恢复、暂时关闭与整体恢复，并保留原有主题、配色和壁纸。

Logo 和浏览器标题可分别保留 DSH 原样或使用自定义标识／产品名称。支持本地 Logo 图片；原生模式释放品牌插槽与浏览器图标，避免强制覆盖。会话标题继续跟随宿主更新。

## 壁纸显示区域

在 **设置 → 外观 → 自定义背景 → 背景显示区域** 选择「整个界面」「仅会话区」或「仅左侧栏」。图片按所选区域填满或完整显示，随窗口、侧栏尺寸自动适配；旧背景记录默认保留整个界面。

清除底部输入区与收起工作台的残留底色，避免遮挡壁纸。面板不透明度越低，壁纸越明显；100% 时面板遮住壁纸。文字不随面板变淡，菜单和弹窗仍使用实色底色。

区域、图片和其他背景参数一起保存在本地，支持刷新、桌面重启和同源标签页同步。降低透明效果时暂时隐藏背景，关闭后恢复。原有主题、28 套配色和图片继续保留。

一并修正会话范围选择器的重复边框；仓库加入已有的 Euler Neon Fluid 单文件演示，该演示不进入插件发行包。

## 使用与升级

在当前 DSH profile 的插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.11`，或在 OMD 版本面板更新。完整重启后确认当前版本为 0.1.7-rc.2.11。桌面端使用应用内插件管理器，保留原数据目录。

## 验证范围

高级定制验证默认布局和四套内置主题下的浅深色、真实分区底色、输入字体与圆角、与壁纸组合、窄屏排版、关闭与恢复；标识与标题验证原生恢复、自定义、刷新、同源标签页同步及恢复入口。

浏览器检查默认布局及四套内置主题、浅深两种模式和三个壁纸区域，用实际截图像素验证选定区域显示壁纸、其他区域不受影响；覆盖输入区、侧栏收起、窄屏、工作台开关、刷新与跨标签页同步。配色矩阵、主题控件和收起面板的回归检查一并执行。

官方 macOS 桌面使用隔离数据验证实际安装、壁纸区域、高级字号及标识／标题在重启后保留、会话与草稿保留和卸载恢复。具体结果见随发行包提供的 `verification.log`；本机未实测 Windows／Linux 原生桌面，跨平台 CI 结果以 Actions 为准。
