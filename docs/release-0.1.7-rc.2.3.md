# Oh My DSH 0.1.7-rc.2.3

本版适配 DSH 0.1.7-rc.2，是 0.1.7-rc.2.2 的后续修复补丁。旧标签与安装包不改写。

## 修复

Windows 旧会话迁移使用宿主提供的原生库，但动态导入转换成工厂调用后，CommonJS 默认值又被包装了一层。本版保持原生库的默认导出，修复 `koffi.load` 不可用引发的迁移失败；不新增运行时依赖或改变权限。

宽范围 V0 迁移保留。完整包含 [0.1.7-rc.2.2 的改动](release-0.1.7-rc.2.2.md)：Web 标题闪烁（#12）、原生 Agent 预设槽位（#13）、空用户占位引发的 400、接口认证、中文请求、长会话效率、缓存释放、档案隔离与目录续读。

## 升级

先等任务结束并备份实际 DSH_HOME。Web 沿用原 profile、目录和端口，安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.3` 或 Release 中的 `trisoul_x-0.1.7-rc.2.3.tgz`。官方桌面版通过应用内插件管理器更新，完整退出后重新打开；不要用普通 CLI 管理 desktop profile。

旧会话原始日志与关联备份保留。回退应使用升级前备份，不手工删除新代际来强迫旧宿主读取。

## 验证范围

迁移、原生导出互操作、native/PTC、空消息修复和打包版 UI 回归分别核验。GitHub Actions 的 Windows/macOS 安装检查与 Linux/Windows 全量回归以对应提交实际结果为准；未结束的检查不当作通过。
