## 范围与不变项

宿主固定为 DSH 0.1.6-alpha.2；继续使用编译后的 CLI。插件、Agent preset、数据目录和原有会话标识不变。主提示词、后台摘要提示词、任务工具规则、原话附件、前置 Trace、压缩策略和配置默认值保留。与升级前 alpha.10 对比，`src/config.mjs`、`src/frequency.mjs`、`src/prompts.mjs`、`src/context/prompts.mjs`、`src/cc-adaptation/` 和 `presets/` 没有改动。

保留已保存的频率、身份、模型、空闲开关和任务设置。默认频率沿用 alpha.10；未通过调整频率、少携带原话或删减功能来取得性能改善。

## 实现优化

| 部位 | 本版处理 | 保持的边界 |
| --- | --- | --- |
| 统计接口 | 输入区只读取轻量快照，完整工作台仍按需读取完整状态 | 指标口径和历史详情保留 |
| 归档 | 文件身份校验后缓存解析结果，磁盘读取缓存有大小预算 | 原件不删除，外部替换、损坏和版本冲突仍可检测 |
| 上下文写入 | 减少无变化写盘，JSON 紧凑序列化 | 原子替换、fsync 和恢复事务保留 |
| 预处理 | 线性计算输入预算，减少重复 JSON 序列化 | 仅移除最旧的参考项，不截断源片段；测试逐字比较旧输出 |
| 长会话界面 | 一次扫描建立各轮操作摘要索引 | 完整工具记录和展开交互保留 |
| 轮询 | 取消过期只读请求，合并同会话 CU 状态查询 | 写请求不因切换界面被擅自取消；独立预览状态保持更新 |
| 构建 | 压缩语法与空白，保留标识名称 | 无新运行时框架、无动态代码改写 |

## 兼容与故障修复

适配宿主会话状态接口、原生用量面板、侧栏和插件热卸载。用量展开状态按会话隔离。修复版本弹窗关闭事件与重新打开的竞争、新建浏览器标签地址栏焦点丢失等问题。另补充压缩方案语义回归：一键应用仍尊重既有中枢方案，明确选段才覆盖模式。

工具模块重复加载时复用已有调度器，不重新执行工具。宿主卸载审核等待真正的移除操作完成；正在移除和已移除的条目不会被误报成导入失败，真实导入和清理错误仍保留。

CU 的官方浏览器入口是独立预览，不替换现有操控链路，也不保证共享登录状态。浏览器、桌面、截图、批注、原话附件、停止、恢复、标签分组与文件交付仍保留。

## 性能测量的含义

`node scripts/benchmark-runtime.mjs` 使用固定合成数据，逐字或深度比较优化前后结果，再取 7 次热运行中位数。一次 Apple M1 / Node 24.18.0 测量中，16,000 条历史节点、450 轮的操作摘要索引从 343.397 ms 降到 3.599 ms；100 份约 6.4 MB 归档的热读取从 28.425 ms 降到 0.494 ms。前端文件从 470,674 字节降至 416,928 字节，gzip 后从 100,333 字节降至 98,256 字节。

这些数字是具体代码路径的微基准，不是模型推理速度、上下文准确率或整个应用的倍数提升。磁盘、系统负载、缓存冷热和会话大小会影响结果；原始性能脚本随源码提供。

## 验证与风险边界

在 macOS 上，本轮 OMD 全量验证为 317 项：314 项通过、3 项因平台或交互条件跳过。另有 Linux Node 22.19、Linux Node 24 和 Windows Node 24 的整套 OMD CI，以及独立的 Windows 宿主热卸载检查。测试包含真实 DSH 工具循环和浏览器操作，但模型响应主要由本地测试提供方生成，不等同于全部真实模型供应商验收。

依赖审计在所用锁文件上未报告已知漏洞；这不意味着未来不会发现新漏洞。源码独立运行的依赖补丁也不代表已自动修改用户另行安装的全局宿主。

误删问题的核实、适用范围和官方打包脚本补丁见 [上游补丁说明](upstream-patches/README.md)。原会话、项目文件、模型凭据和浏览器登录资料不属于发布包；升级仍应保留原数据并先备份。

Windows 托管浏览器先提交初始空白文档，再且仅导航到用户要求的网址；同时按 Playwright 的启动配置关闭 Chromium 开发测试分组，不关闭扩展、历史缓存或显式 WebMCP。目标网页不额外等待网络空闲，也不重复执行失败的导航。

验收将冷启动、只读截图竞争和实际输入分别检查。DPI 切换后，测试先等待已知夹具的无障碍子树恢复，再验证截图与控件的物理坐标、点击、拖拽、中文输入和独立预览；永久缺失或坐标错误仍会失败。最终提交与各平台结果以发行资产 RELEASE-VERIFICATION.md 为准。
