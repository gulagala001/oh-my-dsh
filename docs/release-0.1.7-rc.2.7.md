# Oh My DSH 0.1.7-rc.2.7

**0.1.7-rc.2.7 正式修复版，适配 DSH 0.1.7-rc.2 Web 与官方桌面版，内置 OpenCU 1.1.5。**

## 修复

- 修复电脑／浏览器画面推送结束后继续发送保活消息，触发 `ERR_STREAM_WRITE_AFTER_END` 并导致整个 DSH Host 退出的问题。
- 正常结束、主动断开及同步／异步流错误统一清理定时器、待发画面和观察订阅；断开时尚未完成的订阅也会正确释放，避免重复清理和未捕获异常。
- 禁止宿主 gzip 缓存实时画面推送，保留慢速连接下的最新帧合并和背压控制。
- 修复调整预览尺寸时跳转页面可能卡住旧画面：取消旧截图后，重新请求当前文档，不再保留过期的待处理请求。
- 保留现有记忆、待办、附件、模型、会话、插件兼容与电脑操作功能；本版不修改 Chrome 扩展或原生运行时，无需重载扩展或重新授权。

## 升级

通过当前 DSH profile 的插件管理器安装：

```text
github:gulagala001/oh-my-dsh#v0.1.7-rc.2.7
```

0.1.7-rc.2.5 及以上用户也可在版本面板点击更新。等正在执行的任务结束后，完整退出并重新打开 DSH，或使用“重启应用与 Host”；仅刷新页面不能更新后端。确认“当前版本”为 **0.1.7-rc.2.7**。无需重装宿主或删除任何会话。该版本标记为必要更新。

## 验证范围

流生命周期回归覆盖浏览器／原生观察入口、结束但未销毁的真实响应、订阅建立期间断开、同步／异步写入失败，以及真实压缩中间件下的慢速读者。导航／尺寸调整继续使用原有真实浏览器断言。具体执行记录随发布附件提供；未实测的平台与全量 CI 状态不由本地测试外推。
