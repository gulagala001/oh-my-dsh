# 0.1.7-rc.2.20

本版配套 **DSH 0.1.7-rc.2**，内置 **OpenCU 1.1.8**。更新保留已有模型、会话、附件、主题、插件配置与历史回查。

## 长任务与记忆

新增 Dream，将新增事实摘要与有原话依据的用户决定逐级整理为会话、项目和全局短记忆。默认不自动整理；手动和自动共用额度，支持停止、续跑与故障恢复。独立会话不自动传播到项目或全局，原文、附件及不可变来源版本保留。[Dream 使用方法](dream-memory.md)。

记忆目录可逐层查看和返回，保留搜索、页码与阅读位置。来源展示可辨识名称、版本、事件范围及短预览；长文在独立阅读区展开，迟到响应不打断对话输入。

## 界面与交互

右侧工作台统一导航、标题和内容间距，窄栏保留全部入口；Codex 外观使用可用高度。侧栏支持键盘浏览与窄屏覆盖显示。修复外观保存、模型设置、草稿优化、发送失败、会话切换时的错误反馈、焦点及草稿恢复。

快速连续修改显示偏好时，保留最后一次选择，避免其他设置的旧刷新结果覆盖仍在保存的内容；失败恢复与原生保存队列继续有效。

OpenCU 侧栏显示当前会话时收起重复小窗并释放重复观察；返回后保留位置和选择。小窗改善放大、复位、切换和拖动，遵循减少动态效果设置。

静态页面缺少首次画面通知时，预览主动取得真实首帧，避免一直空白；期间导航只展示新页面，关闭预览或出现对话框时不发布迟到画面。内置浏览器导航时可取消旧截图，后续预览不再堵在旧请求后；过期的自动布局请求不覆盖浏览器退出提示。 缩窄窗口时，浮动预览同步收回会导致越界的尺寸过渡，避免画面短暂滑出窗口。

修复 Windows Chrome 连接从旧安装迁移时的误拒绝。Windows 连接助手按新源码生成运行版本，保留原扩展目录、连接保护与失败回滚；浏览器扩展本身没有变更。

较慢的页面状态首次读取遇到导航变化时，仍可在固定期限内重新观察；停止会中断重读，旧页面的元素引用继续拒绝执行。

## 执行、安装与维护

- 验证命令改用宿主原生 bash／PowerShell 工具，遵守会话沙箱和工具权限。拒绝或取消不覆盖此前验证证据。
- 删除退役项目目录的自动发布分支，保留历史读取；后台请求按优先级和同级先后顺序执行。
- 修复 Dream 执行权接替、损坏历史档案隔离、容量计算，以及预算写入失败时的状态恢复。
- 增加可搬运的离线安装目录；可选插件沿用固定核验版本与宿主安装管理器，支持失败重试。
- README、真实案例与静态文档站同步更新。[全部改动](../CHANGELOG.md#017-rc220)。

## 升级

先结束运行任务并备份实际 DSH 数据目录。在原 profile 安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.20`，完整退出并重启宿主，再核对当前插件版本及旧会话。桌面通过应用内插件管理器安装；完整步骤见[升级指南](upgrade.md)。
