# 装好后的第一次使用

[English](getting-started_EN.md) · [文档目录](README.md) · [公开安装](../README.md#quickstart) · [使用指南](usage.md) · [排障](troubleshooting.md)

这页从已安装、完整重启的匹配环境开始。当前发行为 **`0.2.1-rc.2.omd.0.18.0` / DSH `0.2.1-rc.2`**，默认内置 OpenCU `2.0.1`。先按[安装与版本配对](install.md)确认环境；旧 0.10 用户使用对应固定 tag 文档。

## 1. 确认实际版本与模型

打开左上角版本面板看 **当前版本**；“最新版本”只是远端记录，公开计算排除 `unpublished`。不要把旧公开包配给新宿主，也不要用 `latest` 跨版本选包。桌面和 Web 分属 profile，核对实际完整宿主、插件启用、数据目录与安装来源。

OMD 使用宿主已有模型与凭据，不附带账号。文件任务需要原生工具调用；理解截图还需图像输入。文字／文件使用不要求先准备桌面控制或 Chrome 扩展。

## 2. 选会话、目录与范围

新建会话选择 **Oh My DSH**，已有会话保留原 preset。可选已有工作区；没项目时点工作区标签 **×**，首次发送才创建独立文件目录，继续复用，未发不建。

首次发送前选择记忆范围，开始后锁定：

| 范围 | 用途与边界 |
| --- | --- |
| **会话隔离** | 不自动读取／传播共享记忆，精确历史仍可明确回查。 |
| **项目共享** | 同项目资料与已完成短记忆，便于后续会话继续。 |
| **全局共享** | 精简全局记忆和分页项目目录，细节按需回查。 |

无项目 Chat 的自动目录**不是 Dream 项目**；未加入真实工作区的后代也隔离。改目录或删除历史目录不扩大共享。[Dream](dream-memory.md)

安装默认完整文件／命令访问、关闭执行审批；**profile 显式覆盖优先**。核对当前执行目录和界面权限，记忆范围不决定文件访问权限。冷范围／上下文读取不激活 Agent 或新建账本，保存前再检查会话是否开始。

## 3. 完成一个小文件任务

在可用的已安装环境试：

> 读取这个目录里的 README，说明项目用途、启动步骤与条件。只写实际读到的内容，未说明的事项写“未说明”，保存为 project-start.md 并打开给我检查。

核对正确文件、真实工具返回、交付文件能打开。README 没有启动方式时不要编造。无 README 可准备一份非敏感文件。

## 4. 找到常用入口

| 入口 | 用途与默认行为 |
| --- | --- |
| 星星 | 优化未发送草稿，保留版本；每次额外模型调用，自动轻润色默认关。 |
| **OMD 控制台** | 右侧栏唯一入口：概览、上下文（预处理 → 中枢 → 替换、压缩）、记忆（Dream 自动默认关，全局文件夹空选表示全部）、调用日志、后台日志。`≥` 为已知下界，未知不是零，后台调用也有费用；新会话空态正常。 |
| 输入框下方信息栏 | 原生轮次／Token 统计，加上下文整理与 Dream 作业项；点开后一键跳到控制台对应分区。 |
| **BT** | 待办提醒默认开，验证提醒默认关；“查看任务证据”打开需求、状态与证据。 |
| 模型／Fast | Ultra 提供 Workflow／Agent Team／自由，优先 `xhigh` 否则最高；Agent Team 随 DSH 开关可用；Fast 需匹配 Subscriptions 服务及模型。 |
| **外观** | 五种主题、配色、字体、背景和减少动态效果。 |
| **基础组件** | CodeGraph 等准备状态，保留原生及第三方入口。 |

控制台使用原生右侧栏标签，文件／终端等共存。Tools、证据、CodeGraph 和 Workflow 跟随当前执行目录。OMD-PTC 的普通业务走 `run_code`，匹配作用域保留四个后台直调控制。[完整用法](usage.md)

## 5. DeepSeek 与 CU 边界

DeepSeek Workbench 提供网页聊天与平台入口，可将可提取网页历史导入原生会话，由你自行发下一条，不自动发送。真实账号与持久登录等使用条件见[详细说明](deepseek-workbench.md)。

新版 OpenCU 默认内置。打开 **设置 → 电脑与浏览器** 检查后端、系统权限和浏览器资源；Chrome／Edge 按提示首次配对。完整内置浏览器和原生监看需要匹配的宿主适配，不是装插件就自动修改 stock DSH。先用不含私人信息的小任务开始，操作结果通过实际页面确认。[使用与边界](computer-use.md)

IUI、OMAA 和 Subscriptions 等仍是独立插件，按各自完整版本及[接入边界](plugin-compatibility.md)选择。

遇到问题保留完整版本、实际入口与第一处完整错误，从[症状排障](troubleshooting.md)开始。不要通过清数据或修改版本门禁处理问题。
