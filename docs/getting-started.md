# 装好后的第一次使用

[文档目录](README.md) · [安装教程](upgrade.md) · [完整使用指南](usage.md) · [排障](troubleshooting.md)

这页从“已经安装并完整重启 DSH”开始。还没安装时，先选择[桌面版](upgrade.md#desktop)或 [Web 版](usage.md#安装到现有-dsh推荐)。

## 1. 确认当前环境

打开左上角品牌旁的 **ⓘ**，核对“当前版本”。“最新版本”表示远端发布信息，不能证明安装已生效。桌面与 Web 的插件分别安装在各自 profile；如果找不到 OMD，先按[排障步骤](troubleshooting.md#先确认是否装到了正在使用的环境)核对启用状态和运行环境。

OMD 使用你在 DSH 中配置的模型，不附带账号或密钥。选择支持原生工具调用的模型；需要理解截图时，模型还要支持图像输入。只验证文字对话时，无需先准备桌面控制或 Chrome 扩展。

## 2. 新建一个会话

新建会话，选择 **Oh My DSH** 预设和要工作的目录。已有会话会保留原来的预设，安装插件不会把所有旧会话自动切换过去。

首次发送消息前，在输入区选择摘要共享范围：

| 选择 | 适合什么情况 |
| --- | --- |
| **会话隔离** | 这次对话独立进行，不读取或写入项目共享摘要。 |
| **项目共享** | 同一个项目需要在后续会话中继续使用摘要与详细资料。 |

会话开始后范围会锁定；需要不同范围时新建会话。它控制摘要共享，不决定文件访问权限。

OMD 的默认配置包含完整文件／命令访问并关闭执行审批，profile 中已有的显式覆盖优先。执行任务前，确认选中的工作目录和 DSH 界面显示的权限符合本次工作需要。

## 3. 完成一个小任务

先发一条简短消息确认模型能回复，再让助手读取项目中的 README 并概述用途。可以核对：是否读取了正确文件、工具有没有成功返回、回答是否与文件内容一致。暂时没有 README 时，换成自己准备的非敏感测试文件即可。

这一步验证模型、文件工具与对话流程；它不代表桌面控制等所有组件都已经准备好。操作细节可以展开查看，实际生成的文件可在会话中打开或预览。

## 4. 认识几个常用入口

| 入口 | 用途与默认行为 |
| --- | --- |
| 输入框星星 | 优化尚未发送的草稿，确认后再发送；优化会额外调用一次模型。自动轻润色默认关闭。 |
| **工作台 → 任务** | 查看任务进度与证据；适合多步骤工作。 |
| **BT** | 待办提醒默认开，验证提醒默认关，按会话设置。 |
| **工作台 → 上下文／摘要** | 查看已整理内容和原文回查入口；刚开始没有摘要属于正常状态。 |
| **设置 → 外观** | 切换主题、配色和背景，无需改模型配置。 |
| **设置 → Oh My DSH → 基础组件** | 查看 CodeGraph、浏览器与桌面控制状态，按需准备对应组件。 |

停止会话中的助手工作与停止电脑操控是不同入口。需要接管网页或桌面时，在电脑面板使用停止／接管，完成手动操作后再恢复。[电脑操作步骤](usage.md#开始使用)。

## 接下来

按任务需要继续阅读[后台模型和上下文设置](usage.md#settings)、[外观指南](skins.md)或[电脑操作指南](usage.md#computer-use)。安装或交互遇到问题时，从[排障指南](troubleshooting.md)的症状表开始；反馈时提供“当前版本”和第一处完整错误。
