# 首次使用

[English](getting-started_EN.md) · [文档目录](README.md) · [使用指南](usage.md) · [排障](troubleshooting.md)

这页假设你已经按[安装指南](install.md)装好 OMD 并完整重启了 DSH。

## 1. 确认版本和模型

打开 **设置 → Oh My DSH → 关于**，看 **当前版本** 是不是 1.3.13、DSH 是不是 0.2.2-rc.1。桌面版和网页版用的是不同的 profile，确认装进了你正在用的那个。

OMD 用你在 DSH 里配好的模型，不附带账号。处理文件需要模型支持工具调用，看截图需要模型支持图片输入。

## 2. 新建会话

新建会话，预设选 **Oh My DSH**。可以选一个已有工作区；没有项目的话直接用全局 **新建会话**，OMD 会给这个聊天建一个独立文件夹。

首次发送前，在输入框的 **权限菜单 → 记忆范围** 选记忆范围，发送后就固定了：

| 范围 | 适合 |
| --- | --- |
| **会话隔离** | 一次性的事，不想和别的会话共享 |
| **项目共享** | 同一个项目要分好几次做 |
| **全局共享** | 希望 AI 记得你的通用习惯 |

> OMD 默认让 AI 直接读写文件、运行命令，不逐条询问。你在 profile 里设过的权限优先生效。记忆范围只管记忆，不影响文件权限。

## 3. 做一个小任务

在一个有 README 的目录里输入：

```text
读取这个目录里的 README，说明项目用途、启动步骤和需要的条件。只写实际读到的内容，没写的就标"未说明"，保存为 project-start.md 并打开给我看。
```

检查三件事：读的是对的文件，回答引用了 README 的原话，project-start.md 能打开。README 里没写启动方式时，AI 应该标"未说明"，而不是自己编。

## 4. 认识常用入口

| 入口 | 做什么 |
| --- | --- |
| **OMD 控制台**（右侧栏） | 看 Token、上下文、记忆、调用日志和后台日志 |
| 输入框下方信息栏 | 本轮统计，点开可以跳到控制台 |
| **BT** | 待办提醒和任务验证的开关 |
| 模型面板 | 普通档位和 Ultra（Workflow、Agent Team、自由） |
| **✨** | 发送前润色、理结构或拆步骤 |
| 工具卡片上的 **查看原文** | 翻工具的原始结果 |
| 权限菜单里的 **会话人设** | 给这个会话换人格 |
| `/btw`、`/侧栏` | 问题外话或开临时聊天，不打断主任务 |
| **插件 → Skill／MCP／指令／命令／Hooks** | 管理扩展和项目指令 |

每项的详细用法见[使用指南](usage.md)。

## 5. 网页聊天和电脑操作

- **DeepSeek Workbench**：在 DSH 里打开 DeepSeek 网页聊天，可以把网页上的历史导入成 DSH 会话，下一条由你自己发。见 [DeepSeek Workbench](deepseek-workbench.md)。
- **电脑与浏览器**：打开 **设置 → 电脑与浏览器**，按提示授予系统权限、准备浏览器，或连接 Chrome／Edge 扩展。先拿一个不涉及私人信息的小任务试试。见[电脑与浏览器](computer-use.md)。

遇到问题先看[排障](troubleshooting.md)，记下完整版本和第一条报错。不要靠清空数据来解决问题。
