# 0.2.0-rc.2.omd.0.7.0：ChatGPT Fast 与旧会话恢复

本版配对官方 DSH `0.2.0-rc.2`，用于现有官方桌面。OMD 功能版本由 `0.6.1` 升至 `0.7.0`；宿主、SDK 与内置 OpenCU 保持原配对。

## 本版改动

- ChatGPT 订阅渠道的 Fast 按钮显示为紧凑闪电，点亮表示开启。继续使用 dsh-plugin-subscriptions 的原生回调，状态按会话保存；其他渠道及不支持 Fast 的模型隐藏。扩展重载和卸载正确恢复插槽。
- 兼容已核对结构的 `dream-command`、`instruction-hint`、`agent-teams-command` 旧会话来源，保留其身份、原始日志、引用重映射和原生迁移校验。
- 单份正文损坏或格式暂不支持的会话只产生逐会话警告，健康会话的 Dream 索引、自动整理和共享作业继续执行。异常来源退出共享汇总，最后可读记忆保留；日志变化或手动刷新后重新检查。
- 长会话预处理回复校验失败、短重试用尽后，新增真实事件达到原有间隔可触发一次恢复尝试。同一路由主请求成功可恢复可恢复的后台提供方失败，保留退避和重启后的恢复信号。
- 保留摘要校验、压缩节奏、独立后台模型隔离，以及中断迁移事务的严格恢复规则。
- 推荐插件加入 V1ki 的订阅登录插件，复用原生安装管理器。

## 安装与升级

安装来源：`github:gulagala001/oh-my-dsh#v0.2.0-rc.2.omd.0.7.0`。升级前结束任务、停止服务或完整退出应用，并备份实际 `DSH_HOME`；安装后完整重启。账号、会话与配置沿用原环境。
