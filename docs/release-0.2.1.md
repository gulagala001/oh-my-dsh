# 0.2.1

修复上下文预处理提前续跑的问题。正常自动预处理同时满足新增事件间隔（默认 48 条）和最低文本量（默认约 8,000 tokens）才启动，一次只处理一窗。只有实际失败后的重试可以补齐多窗，默认最多两窗，每窗仍受最低文本量约束。未达到门槛时保留原文和新增事件计数；窗口可随新内容增长，避免短窗口一直挡住后续材料。

沿用既有配置字段，设置界面明确区分“失败重试最多处理窗口数”和“预处理最低文本量”。已有会话、摘要、模型和参数保留。本版继续配对 DSH 0.1.7-rc.2，内置 OpenCU 1.1.8。

## 升级

在原安装入口更新到 `github:gulagala001/oh-my-dsh#v0.2.1`，重启宿主后确认当前插件版本为 0.2.1。详见[升级指南](upgrade.md)。

## 验证

本次进行预处理频率、最低文本量、失败恢复、上下文窗口、设置和文档的针对性回归，并完成构建。具体检查见 Release 的 verification.log；不将本次局部修复称为全平台重新验收。
