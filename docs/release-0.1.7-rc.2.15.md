# OMD 0.1.7-rc.2.15

本版配套 DSH 0.1.7-rc.2，继续内置 OpenCU 1.1.7。

推荐插件新增 **需求理解 · OMD UI 增强版 0.1.0**，源码与安装包独立发布在 [omd-prompt-optimizer](https://github.com/gulagala001/omd-prompt-optimizer)。它复用 WestFox-AwA 的 dsh-prompt-optimizer 0.7.4 解释与校验引擎，采用 OMD 风格界面与独立启停逻辑。

**不会自动安装。** 只有在“设置 → 推荐插件”点击安装才获取插件。安装后还需在“设置 → 需求理解”主动启用，默认采用审查模式。开启自动更新也不会安装尚未安装的推荐项。

OMD 本体本次只增加推荐信息，不把解释器、Bash 或额外自动调用加入内置组件。已有提示词优化、记忆、压缩、前置推理、待办和电脑操作链路不变。
