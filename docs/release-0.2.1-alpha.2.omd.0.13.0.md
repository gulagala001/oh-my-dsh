# 0.2.1-alpha.2.omd.0.13.0（开发候选）

[返回项目介绍](../README.md) · [安装与升级](upgrade.md)

本轮优化对话、侧栏、Pro／Ultracode、五套明暗主题、统一工作台和配套插件的前端流程，内置 OpenCU 1.5.0。此版本尚未公开发布；GitHub 安装命令仍指向已经发布的版本。

- 侧栏使用原生导航结构，改善搜索、选中层级与键盘操作，保留第三方内容和明暗主题。
- Pro／Ultracode 使用更轻的动态光效；系统和手动减少动态效果均生效。
- 窄屏工具栏减少重复文字，保留工作台、电脑、用量、停止、接手和恢复入口。悬浮预览保留当前目标，可展开多目标、放大和拖离。
- 工作台统一间距、长内容、状态、焦点与滚动；失败保留原因和重试入口。
- OMAA 0.15.0、Intelligent UI 1.0.2、Subscriptions 0.9.9-omd.3 和 Intent 0.3.2 的对应开发候选同步改善错误、保存、弹窗和冷恢复流程。
- REA 已纳入按需开发调查流程，用于发行工件和运行边界；产品验收仍依据实际宿主、工具执行和界面操作。[开发说明](rea-development.md)。

alpha.2 为当前主构建。rc.2 和 alpha.1 使用各自 SDK、组件快照与依赖锁的独立构建，完整版本号分别为 `0.2.0-rc.2.omd.0.13.0`、`0.2.1-alpha.1.omd.0.13.0`。候选工件以本地验收记录为准，不从主构建改写版本号制作旧宿主安装包。

本轮 macOS 隔离 Web 验收覆盖真实原生工具、PTC、前端、插件加载顺序、启停、重启和卸载。会话模拟器覆盖八个基线场景。Windows／Linux、真实付费账号与桌面硬件权限流程的未实测部分不标为通过；官方桌面应用仍使用它实际附带的宿主版本。

README 和产品页的 Launchpad 实拍使用本地受控模型与虚构资料，实际执行下载、文件核验、任务证据、压缩和原文回查。[素材与范围](showcase.md)。
