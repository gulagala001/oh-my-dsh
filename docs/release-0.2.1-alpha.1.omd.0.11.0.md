# OMD 0.2.1-alpha.1.omd.0.11.0（未正式发布）

本构建为已完成本地验收的交付，尚未正式发布。配对官方 DSH 0.2.1-alpha.1，保留该宿主对应的 SDK、原生组件快照与依赖锁定；请勿混装另一宿主的 OMD 构建。

新增独立可选插件 [智能交互回答 · Intelligent UI](https://github.com/gulagala001/dsh-intelligent-ui)。默认不安装。它提供智能聊天入口，使用 DSH 原生模型和会话；普通 agent 仅通过短 skill 按需使用，不向 OMD 全局主提示增加组件规范或新工具 schema。控件操作默认更新界面状态，明确提交后才继续对话。实际回答质量取决于所选模型，不宣称等同 ChatGPT。

推荐管理器读取正在运行的 DSH 完整版本，当前宿主选取 `0.2.1-alpha.1.iui.1.0.0`，固定对应 GitHub tag、安装包资产与 SHA-256，不跟随 `latest`。缺失校验值或无法核实宿主时拒绝安装与更新；已有安装仍可卸载。未正式发布期间，固定在线下载入口不构成可用发行承诺。

切换宿主后，旧宿主构建需手动点击“更新”换为对应包；即使开启推荐插件自动更新，也不会自动跨宿主换包。手动换包保留原启用状态和保存的界面状态数据。

两条宿主均已完成 Mac 隔离原生 Web 的标准包安装、启停、进程重启、会话隔离、重新安装、取消恢复、卸载及 OMD 双向加载顺序共存；推荐页核对实际 Loader 宿主、预期版本、SHA 与默认不安装。OMD 完整八场景会话基线及真实 Web 通过。IUI 在 alpha.1 原生循环使用已配置供应商模型完成五类交互验收，保留首次失败、显式修复与限额中止证据；控件操作不额外调用模型。

原生桌面 App、Windows/Linux 与 OMD 整套共存尚未同等实测；独立 IUI 的跨平台原生 Web CI 由其验收记录列出，不能替代 OMD 整套的平台证明。当前公开下载安装由“未正式发布”限制关闭，保留本地包安装与已有安装卸载。最终包与 SHA 在本地交付目录保存，后续与插件生态兼容性工作合并验收后再统一发布。
