# Codex Desktop · 全新布局

在「设置 → 外观 → 皮肤」选择 **Codex Desktop · 全新布局**。本套独立制作，使用新 id `codex-desktop`；既有 Codex 和 iOS 皮肤继续保留。

主依据是用户于 2026-09-20 提供的当前 Codex 桌面截图：冷灰侧栏、黑底白字用户消息、悬浮右侧卡片、白色圆角输入区。早期公开截图仅用于补充设置与弹窗状态，不能覆盖用户当前界面的视觉要求。只参考图片，不继承旧皮肤代码，也不将产品截图打入发行包。

布局包含冷灰侧栏、紧凑标题栏、对话/轨迹切换、反色用户气泡、细线过程记录、大圆角输入区及悬浮式工作台。设置使用窄导航与紧凑表单，外观页提供主题预览、明暗模式、皮肤导入、降低效果和历史加载数量。原生模型、权限、BT、文件入口、运行停止和各工作台分页继续使用真实宿主组件。

浅色背景 `#FFFFFF`、正文 `#0D0D0D`，深色背景 `#181818`、正文 `#FFFFFF`；输入区深色为 `#262626`。按本次用户指定，强调色采用浅色纯黑、深色纯白，覆盖按钮、开关、选中入口和焦点。侧栏使用冷灰色渐变。UI 和正文使用 macOS 系统字体（中文回退苹方），代码使用系统等宽字体栈，SF Mono 不可用时回退到 Menlo（本机 Chromium 实测如此），其他平台有系统回退；不分发 Apple 字体文件。UI 默认 14px，正文继续尊重宿主字号设置。窄屏提供完整导航页和横向设置导航，支持系统明暗、减少动态效果及一键恢复默认。

布局通过随插件发布的 `codex-desktop` 适配器启用；导入皮肤仍不能执行脚本或任意布局 CSS。1.0.1 的顶栏横跨对话与工作台，右侧栏开关固定在窗口最右端。右栏默认宽度为 360px，通过宿主布局存储的原生动作设置，测量与拖动保持一致；拖动后的宽度仅作为这套皮肤的浏览器偏好保存，切换其他皮肤恢复原宽度。适配器使用 DSH 0.1.6-alpha.2 根布局注册的共享存储，不重排 React 节点。DSH 与 Codex 的实际业务入口不同，本套按 DSH 功能适配，不添加无实际功能的产品按钮。

源文件：`src/client/skins/codex-desktop/`。运行 `node scripts/build.mjs` 自动生成内置包和客户端；需要导出时运行：

```sh
node scripts/pack-skin.mjs src/client/skins/codex-desktop dist/skins/codex-desktop.omd-skin.json
```

验证入口：`test/codex-desktop-ui.test.mjs`，覆盖明暗、设置与工作台分页、窄屏、发送/停止、刷新与恢复默认。设置 `TRISOUL_UI_ARTIFACTS=1` 时将真实 DSH 截图保存到 `data/codex-desktop-qa/`。
