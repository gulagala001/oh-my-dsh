# Codex Desktop 外观

[文档目录](README.md) · [外观指南](skins.md)

在 **设置 → 外观 → 皮肤** 选 **Codex Desktop · 全新布局**（id 为 `codex-desktop`）。这套外观参照 Codex 桌面版的截图独立制作，不包含 Codex 的代码或截图。

## 样子

- 冷灰渐变侧栏、紧凑标题栏、对话和轨迹切换、反色的用户消息、细线过程记录、大圆角输入区和悬浮的右侧工作台。
- 设置页用窄导航和紧凑表单；外观页有主题预览、明暗模式、皮肤导入、降低效果和历史加载条数。
- 浅色背景 `#FFFFFF`、正文 `#0D0D0D`；深色背景 `#181818`、正文 `#FFFFFF`，深色输入区 `#262626`。强调色浅色用纯黑、深色用纯白。
- 界面和正文用系统字体（中文回退到苹方），代码用系统等宽字体，没有 SF Mono 时用 Menlo。不附带 Apple 字体文件。界面默认 14px，正文跟随 DSH 的字号设置。
- 窄屏有完整导航页和横向设置导航，支持系统明暗、减少动态效果和一键恢复默认。

模型、权限、BT、文件、停止按钮和工作台都是 DSH 原生的控件，只换了样子。DSH 没有的功能不会多出按钮。

## 右侧栏

顶栏横跨对话和工作台，右侧栏开关固定在窗口最右边。右栏默认宽 360px，拖动后的宽度只在这套外观下记住，换别的外观会恢复原宽度。

在右侧栏选 **OMD 控制台**，可以切换概览、上下文、记忆、调用日志和后台日志。浏览器、文件、终端和第三方插件的入口都还在，切换标签不会丢掉未保存的编辑。

## 导出

源文件在 `src/client/skins/codex-desktop/`。`node scripts/build.mjs` 会生成内置包；要导出成文件：

```sh
node scripts/pack-skin.mjs src/client/skins/codex-desktop dist/skins/codex-desktop.omd-skin.json
```

导入的皮肤文件只能改颜色和参数，不能带脚本或布局代码；完整布局由 OMD 自带的适配器提供。
