# Oh My DSH 0.1.6-alpha.2.4

本版为普通更新的预发布版，适配 DSH 0.1.6-alpha.2。

- 明确 Todo 创建时顶层摘录与每条任务的锚点均须填写 `from/to`；短引用允许两者相同。仅调整工具描述，保留执行与校验规则。
- 新增推荐插件设置页，支持标准插件包安装、更新、卸载及默认关闭的自动更新；展示需要手动配置的插件说明。
- 修复通用工具卡片开头时后续文件操作被隐藏且无法展开的问题。

## 安装与升级

停止服务后使用原 profile 安装，沿用原 `DSH_HOME`、模型配置和凭据：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v0.1.6-alpha.2.4
```
