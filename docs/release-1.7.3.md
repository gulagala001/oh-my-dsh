# Oh My DSH 1.7.3

适配 **DSH 0.1.7-rc.2 Web 与官方桌面版**，内置 **OpenCU 1.1.3**。旧 rc.1 宿主继续使用 OMD 1.7.2。

- 同步新版工具、Shell、Jobs、Conversation 与 Chat，保留 OMD 的上下文、任务验证、BT、PTC、电脑操作和主题。
- 上下文替换、全量压缩与会话回放保留动态工具启停声明，避免后续请求丢失宿主工具状态。
- 接入新版快捷键、动态工具展示、账号额度提示与桌面图片处理。
- 修复首次安装时上传服务的旧注册残留，以及嵌入聊天组件的样式归属；修正窄屏主题气泡溢出和 Material 设置焦点。
- 修复 Chrome 扩展刷新状态时可能漏掉用户停止／断开操作的竞态。
- 同步托管浏览器的 Chromium 截图参数，修复 Windows 后台标签页截图可能挂起的问题。
- 皮肤明暗切换等待宿主保存确认，避免保存期间被旧设置快照临时切回原主题。

## 安装与升级

已有环境先等任务结束、停止服务并备份完整的实际 `DSH_HOME`，保留原 profile 和端口。

Web：

```sh
npx --yes @deepseek-ai/dsh@0.1.7-rc.2 plugin --profile web add github:gulagala001/oh-my-dsh#v1.7.3
npx --yes @deepseek-ai/dsh@0.1.7-rc.2 --profile web
```

桌面：安装官方 DSH 0.1.7-rc.2，在应用内「插件」安装 `github:gulagala001/oh-my-dsh#v1.7.3`。它使用独立的 `desktop` profile，不能通过 CLI 管理。

**桌面安装、更新或启停后，需要从应用菜单选择「重启应用与 Host」，或完整退出再打开。** 仅关闭窗口会留在后台，刷新页面会复用旧启动配置。rc.2 桌面不能安全热切换完整的会话组件，本版会提示重启，不自动中断正在运行的任务。

重启后检查当前版本为 1.7.3、原会话和模型仍在。新会话选 Oh My DSH；既有会话保留各自模式。Web 和桌面的插件启用状态分别管理。
