# OMD 0.1.7-rc.2.19

本版配套 DSH 0.1.7-rc.2，继续内置 OpenCU 1.1.7。

修复普通 fork 会话无法切换模型的问题。普通 fork 同样带有父会话字段，此前被误判为子代理；现在按实际子代理身份判断，fork 可独立选择模型与开启 Ultracode，真正子代理仍受保护。

模型与思考强度浮层从约 290×137px 收紧至 256×100px，缩小标题、模型名、重置图标和留白，保留滑条操作区域、模型搜索列表宽度和触摸适配。临时提示或错误出现时仍按内容扩展。

## 升级

对应 Release 发布后，等待当前任务结束，在 OMD 版本面板更新到 `0.1.7-rc.2.19`，然后完整退出应用与 Host 并重新打开。桌面使用原生插件管理器，不使用 CLI 修改 `desktop` profile。升级保留模型、会话、Ultracode、外观和其他插件配置。
