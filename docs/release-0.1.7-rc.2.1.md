# Oh My DSH 0.1.7-rc.2.1

适配 **DSH 0.1.7-rc.2 Web 与官方桌面版**，内置 **OpenCU 1.1.4**。

- 恢复 macOS 桌面端左上角的版本信息入口 ⓘ。新版宿主使用普通品牌容器，插件现在兼容该结构，并避免依赖不同安装包生成的样式类名。
- 保留网页端品牌导航、版本弹窗、更新标记，以及侧栏收起和展开后的入口恢复。
- 版本号改为完整 DSH 宿主版本加插件补丁号：本版为 `0.1.7-rc.2.1`，同一宿主的下一次插件补丁为 `0.1.7-rc.2.2`。

## 安装与升级

桌面版在应用内「插件」安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.1`，待任务结束后完整退出应用并重新打开；提供「重启应用与 Host」菜单的版本也可使用该入口。Web 沿用原数据目录和 profile 安装同一 tag。详细步骤见[安装手册](upgrade.md)。

**旧 1.x 检查器无法自动识别本次编号切换，需要按新 tag 手动更新一次。** 更新后新检查器会正确处理旧编号和后续插件补丁。历史 tag 与安装包保持原样，版本数字变小不表示功能回退。

本版只包含版本入口和编号切换相关修复；旧 V0 会话历史兼容修复仍待发布，相关状态见安装手册。
