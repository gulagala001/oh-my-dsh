# Oh My DSH 使用指南

[English](usage_EN.md) · [文档目录](README.md) · [首次使用](getting-started.md) · [安装与升级](upgrade.md) · [更新与卸载](#update-uninstall) · [排障](troubleshooting.md) · [开发入口](development.md)

OMD 是 DSH 插件，继续使用宿主的模型、项目、会话、文件、工具和技能，新增能力围绕当前对话展开。

公开配对为 DSH `0.2.1-alpha.1`／OMD `0.2.1-alpha.1.omd.0.10.0`，或 DSH `0.2.0-rc.2`／OMD `0.2.0-rc.2.omd.0.10.0`。GitHub `main` 的 alpha.2 OMD `0.16.0` 未发行，已整合 OpenCU 1.6.1 的浏览器与运行时重构。下文标注新增范围，公开包以对应固定 tag 文档为准。

## 安装到现有 DSH（推荐）

桌面用户先看[桌面教程](upgrade.md#desktop)。下列命令适用 alpha.1 Web；已有环境先结束任务、停止服务并[备份](upgrade.md#2-停止并完整备份)。

需要 Node.js ≥22.19、Git 和公开版本使用的 pnpm 11.23.0；Windows 用 PowerShell 7。在与原服务相同的 `DSH_HOME` 下执行：

```sh
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile web add https://github.com/gulagala001/oh-my-dsh/releases/download/v0.2.1-alpha.1.omd.0.10.0/trisoul_x-0.2.1-alpha.1.omd.0.10.0.tgz
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 --profile web
```

打开本次启动的完整登录链接。新 Web 默认 3080；已有环境沿用端口与启动方式。自定义 profile 替换 `web`；安装与运行指向同一数据目录。

默认预设为 `trisoul-x`（Oh My DSH），允许完整文件／命令访问、关闭执行审批；**profile 显式覆盖优先**。旧会话保留预设。桌面独立 `desktop` profile 不能由普通 Web CLI 管理。

<a id="update-uninstall"></a>

<details>
<summary>更新、停用与卸载</summary>

更新先备份，按宿主选[固定发行](upgrade.md#目标版本与完成标准)。版本面板“更新”使用当前 profile 原生管理器，不升级宿主或自动重启，不用 `latest` 选包。

安装、更新、启停后完整重启：桌面用“重启应用与 Host”或完整退出重开，Web 重启原服务。关窗口或刷新不能替换运行后端。

Web 卸载：

```sh
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile web remove trisoul_x
```

桌面用应用插件页或[自带 CLI](upgrade.md#desktop-cli)。卸载保留模型、凭据、会话和资料；旧 OMD 会话需恢复其预设才能续用。新 standard 会话可继续使用 DSH，不表示旧 OMD 会话已自动转换。

</details>

## 无项目聊天

鼠标移到已选工作区标签，点 **×** 取消。草稿、附件、模型和权限保留，也可重新选工作区。

首次发送后在 DSH 所在电脑创建独立目录，默认 **文稿（Documents）/DSH/日期/首条消息名**，重名编号。未发送不建目录；刷新、重启或继续聊天使用原目录。另开聊天建新目录，显示在“未分组”，不加入工作区列表。

权限显示“自定义”时先选预设；同步失败保留草稿并提示重试。

## 日常使用

把目标、材料与需要保留的条件一起交给助手。多步骤工作可要求建任务、完成前检查产物：“整理清单，保留未验收项，下载 CSV 并核对字段，再交付。”

**BT** 按会话保存：待办提醒默认开，验证提醒默认关。开启验证检查缺证据或文字证据，可能多花时间和 Token；关闭不影响账本与工具。阻塞时可暂停本回合催促，不会误勾完成。

`todo_write` 管任务、摘录与锚点，`verify_link` 管证据和实际检查。开发分支还保留工具调用身份、命令、退出状态和起止时间。完成状态不等于检查通过。

[![任务实拍：CSV 编码、条数与全部字段检查通过](site/media/launchpad-tasks.jpg)](showcase.md)

### 模型与工作模式

模型入口提供原生推理档、**Pro** 和 **Ultracode**。Pro 用于拆解、按需委派与持续推进；Ultracode 增加完整性和对抗验证。推理档按模型声明选择，两种模式分别保存；切模型保持模式，选原生档或恢复默认关闭模式。[Workflow](workflow.md)。

**OMD-PTC** 通过 `run_code` 使用工具，保留 OMD 上下文、任务、技能和电脑操控。与 Oh My DSH 共用设置，任务和会话各自独立，宿主 PTC 预设也保留。

## 上下文与记忆

后台保存事实摘要、用户决定和详细资料，按需替换请求中的历史表示。原话与附件留档；需要精确条件时说：“回查最初消息的 CSV 编码和列顺序。”

[![压缩后回查最初的 BOM 与六列要求](site/media/launchpad-recall.jpg)](showcase.md)

首次发送前选范围，开始后锁定：

| 范围 | 用途与边界 |
| --- | --- |
| **会话隔离** | 不自动读取共享记忆，整理内容不传播到项目／全局。 |
| **项目共享** | 使用同项目摘要与资料；开发分支还注入已完成项目短记忆。 |
| **全局共享**（开发分支） | 注入精简全局短记忆和项目目录，细节按需回查。 |

范围控制记忆共享，不控制文件权限；明确要求时各范围均可回查其他会话。

<details>
<summary>压缩、Dream、频率与费用</summary>

**上下文 → 异步压缩** 选择本会话模式。默认“原版异步”按窗口整理；“主动异步”由独立请求判断范围。主模型继续工作，下一请求只应用完成结果；切换取消旧请求，原文和资料保留。[上下文详情](context-workflow.md)。

开发分支 **记忆 · Dream** 可整理会话、项目、全局，搜索分页并回查来源。默认只读新增摘要，长期无活动会话才补原文。自动默认关，开启后默认每小时检查，手动与自动共用每日 200,000 Token 上限；停止保留进度。[Dream](dream-memory.md)。

常用设置中默认频率“适中”，空闲预处理默认关，启用默认等待 90 秒。后台模型可跟随或单配，仍有费用，不保证省费。模型窗口始终有限，监控的估算与实际计费用量分别显示。

</details>

## 提示词优化

点输入框星星，选 **轻润色、结构化、步骤规划**，填额外要求后开始。确认后发送，可撤销、重做、恢复原稿、继续优化或保存要求预设。

自动发送前润色默认关；开启每次额外调用当前模型，用轻润色处理草稿。不会读附件正文或整段历史。优化中修改草稿／附件时结果等待应用；停止、错误、超时、切会话不自动发送。

<details>
<summary>草稿保存与发送失败</summary>

每会话最多 20 个版本；刷新清空优化版本，文字草稿由宿主保存。偏好与要求预设在当前浏览器保存，同源标签同步，其他设备不自动同步。

开发分支支持发送失败恢复原稿／版本，以及本页面内切会话保留未发送附件和优化记录。已经编辑另一份草稿时保留版本单独显示，查看不立即替换当前文字；刷新／关闭不保留这些文件与版本。

</details>

## 设置与保存

设置分常用、基础组件、模型与身份、实验性功能、高级和全局背景。普通修改点 **保存设置**；基础组件开关立即保存，运行时路径变化需重启。

人格可选默认、硬邦邦、软乎乎、自定义、关闭，保存后下一请求生效。内置文案可预览并复制到自定义，切换不删已保存自定义内容。

全局背景手动维护；冲突时 **读取最新版本**，比较后合并或采用最新内容，再保存。读取不覆盖草稿。

[![主题、配色、字体与背景设置](site/media/launchpad-appearance.jpg)](skins.md)

外观提供 OMD 默认、Codex Desktop、iOS Liquid Glass、Claude CLI、Google Material，均有明暗。主题、28 套配色和背景独立，可改字体、字号、分区颜色、Logo、标题和减少动态效果。[外观详情](skins.md) · [主题实拍](showcase.md#主题与设置)。

## CodeGraph

在基础组件查看状态。选择代码项目自动准备 `.codegraph/`，直接问“登录请求经过哪些函数？”或“改此函数影响谁？”。失败可重试，普通文件与搜索继续可用。

## Computer Use

OMD 内置固定 OpenCU 快照，无需另装。OpenCU 也能[独立使用](https://github.com/gulagala001/opencu)，不强制 OMD；共同安装见[兼容说明](plugin-compatibility.md#opencu)。

指定浏览器／应用目标，助手操作时查看画面。**查看不等于接管，关预览不等于停止。**

最新本地实现已收敛为一个 **浏览器** 入口，用户填写并保存后，助手可恢复读取同一页面。[采购单实拍](showcase.md#当前本地案例采购单)展示这条流程；它尚未公开发行，旧包仍按对应 tag 的入口操作。

### 开始使用

1. 选原生工具模型；理解截图需图像输入。
2. 在 **基础组件** 或 **电脑 → 运行环境与权限** 查需要的组件。
3. 最新本地实现使用统一 **浏览器** 入口；公开包按该版本通过 `@Browser`、已连接 Chrome 标签或应用引用指定目标，说明目标和材料。
4. 通过 **电脑** 查看，手动操作前 **停止／接管**，完成后 **恢复助手控制**。

例如：“筛选待验收项，导出完整清单，核对下载并交付。”案例实际完成筛选、刷新恢复和下载，保留 8 条事项、3 条待验收。

[![实际示例网页：搜索、筛选与 CSV 导出](site/media/launchpad-browser.jpg)](showcase.md)

### 平台与运行条件

| 部分 | 条件与本轮边界 |
| --- | --- |
| 文件、任务、上下文、主题 | 不依赖原生桌面控制，随匹配宿主运行。 |
| 浏览器 | 独立配置与日常登录分开；Chrome 扩展首次按提示加载，更新后重新加载。 |
| macOS 桌面／窗口分享 | macOS 14+，辅助功能与屏幕录制权限；旧公开包编译需 Apple Command Line Tools。 |
| Windows 桌面 | 面向 Windows 10 2004+ 常见单屏流程；旧公开包编译需 .NET 10 SDK。本轮未做 Windows 实机验收。 |
| Linux | 通用与浏览器能力，本版无 Linux 原生桌面控制。 |

**最新本地实现**使用固定官方预编译浏览器运行时，完整平台包提供预编译原生组件，普通安装无需编译。缺匹配组件提示安装完整包，源码编译仅限明确启用的开发模式。该实现已整合至 GitHub main，公开 `0.10.0` 仍不包含这些改动，不能据此说旧包无需 SDK。

<details>
<summary>浏览器、下载、查找与设备预览</summary>

<a id="网页登录状态与原标签恢复"></a>

切标签只变查看网页；点击、输入、导航、改样式才停止并接管，可返回助手当前画面。外部打开使用 DSH 所在电脑的默认浏览器，远程时不是客户端。

地址栏可导航、刷新、停止；菜单有历史、查找、下载与设备工具栏。历史只记会话接入后网页。下载可搜索、筛选、刷新，清记录不删文件或取消下载。

尺寸与触摸、DPR、User Agent 分别设，应用才接管；预览缩放只改显示，截图只读不暂停。

开发分支内置浏览器下载可保存持久附件，原生／OMD-PTC 可预览，停止或重启后可读，重复保存复用文件。扩展下载留原浏览器位置，仅同步状态。

内置与日常配置分开。原标签仍在时优先重绑，新标签不复制 sessionStorage；登出、重启或过期仍可能要登录。

</details>

<details>
<summary>分享窗口、批注与样式</summary>

分享窗口把截图和可访问性文字加入草稿，检查后发送，不取得控制。批注页面圈选或选元素，把图、说明、元素信息加入草稿；取消不加附件。

样式预览暂停助手，临时改真实网页并采集后恢复，不改源码。按批注改源码后需实际打开检查；继续操控前恢复助手。

</details>

<details>
<summary>导出、WebMCP 与恢复</summary>

<a id="执行预算与重置恢复"></a>

可导出 MHTML、保存已加载图／字体／样式／视频，报告失败素材，文件成为持久附件。懒加载先加载；不是完整会话备份，不提供完整流媒体或 Workspace 专用格式。

兼容 Chromium 153+ 可调用页面 WebMCP；未注册时继续普通操控。

`computer_use` 默认预算 30 秒，可设 1–300000 毫秒，停止始终有效。超时不等于撤销，继续前观察。重置清 JavaScript 变量，原标签仍在可重绑，避免重复提交。

</details>

## 侧问与回合回滚

`/btw 问题` 复用主模型最近已发出的请求上下文，主任务运行中可看答案，不执行工具。`/btw cancel` 只停侧问；冷启动先等主请求建立，不进入项目／全局 Dream。[原项目](https://github.com/JasonQQ/dsh-btw-plugin)。

Turn Rewind 可选，固定上游 `0.3.9` 被 alpha.1 原生门禁拒绝，rc.2 可按目录手动安装，不绕过检查。[来源与许可](../THIRD_PARTY_NOTICES.md)。

## 数据与维护

数据在实际 `DSH_HOME`，Web 默认用户目录 `.dsh`，OMD 资料位于 `trisoul-x/`。源码默认仓库 `data/dsh/`。完整备份包括 profile、凭据、会话、附件、OMD 资料，外部项目／索引另备份。

旧自动记忆只读，不恢复旧执行器。卸载不清用户资料，迁移回退按[升级指南](upgrade.md)。

## 版本与更新提醒

面板区分当前版本和远端更新，显示说明、进度、错误、待重启。绿点普通更新，红点必要修复。检查不调用模型或发会话内容，失败不算最新版。

按[完整配对](upgrade.md#目标版本与完成标准)选包，重启后查当前版本。更新只管当前 profile 的 OMD，宿主另升级。
