## 安装到现有 DSH

选择 **[复制指令给 AI 安装](install.md#ai)** 或 **[通过“添加插件”安装](install.md#gui)**。安装页提供 DSH 0.2.1-rc.1／0.2.1-rc.2 对应的固定地址，OMD 已包含 OpenCU。

完整重启后新建会话，选择 **Oh My DSH**；已有会话保留原 preset。模型沿用你的 DSH 配置，权限以现有 profile 的显式设置为准。

<details>
<summary>更新、停用与卸载</summary>

升级先备份，再按真实完整宿主选择固定发行。版本面板只操作当前 profile 的 OMD，不升级宿主，不自动重启。当前版本与远端版本分开；公开计算默认排除 `unpublished`，展示和安装前均拒绝未发布目标。没有对应公开成品时，不为本地候选伪造下载入口。

安装、更新、启停后，等任务结束再完整重启应用或原 Web 服务，关窗口或刷新不替代后端切换。以下为 DSH 0.2.1-rc.2、web profile 的卸载示例；桌面请使用插件页：

```sh
npx --yes @deepseek-ai/dsh@0.2.1-rc.2 plugin --profile web remove oh-my-dsh
```

停用／卸载保留模型、凭据、会话、草稿和记忆；缺少 OMD preset 的旧会话需重新启用插件后继续。新 standard 会话可运行不证明旧会话已经转换。Loader 的配置保护不把 bundle effective patch 写回用户配置，卸载保留第三方注册和包装。

</details>

## 无项目聊天

每个工作区复用一份未发送草稿，全局“新建会话”单独复用一份。重复新建或切换预设保留对应草稿的文字和附件；工作区标签上的 **×** 打开全局草稿，选择工作区则打开该工作区的草稿，各自内容不互相覆盖。

各工作区和全局分别记住最后一次手动选择的模型渠道、模型和思考档位。查看旧会话或自动恢复设置不会更新这些偏好，正式会话保留自身的模型；首次使用沿用默认选择。记住的渠道不可选时会提示重新选择，草稿保留。

全局草稿首次发送才在 DSH 所在电脑创建独立目录，默认 **Documents/DSH/日期/首条消息名**，重名编号；刷新、重启或继续复用原目录，另开聊天才建新目录。这些目录不注册成工作区，聊天显示在“未分组”。发送成功后清空并继续复用全局草稿载体，不为每个聊天留下新的空白会话；发送失败保留原稿供重试。

**自动文件目录不是 Dream 项目。** Chat 及未另行加入真实工作区的后代保持隔离；改默认保存根目录、改执行目录或删除原目录，不会把历史 Chat、旧 Dream 作业误纳入共享。归属异常暂时隔离共享并保留诊断，基础聊天继续。用户明确加入真实原生工作区后，按其归属与所选范围处理。[Dream 隔离](dream-memory.md)

权限显示“自定义”时先选权限预设；同步失败保留草稿并提示重试。文件访问权限与记忆共享范围是两件事。

创建过程中切走会话会取消剩余准备并释放等待，原稿和附件保留，重试复用同一次目录分配。消息已交给宿主后再切走，仍按实际发送回执收尾；失败可重试，不会因切换自动重发。

首次创建若因磁盘错误或程序退出而中断，重试会保留已存在但尚未确认归属的目录，另选编号，不把其中的文件带入聊天。创建已确认的聊天仍复用原目录。

## 界面与入口

右侧栏引导页的 **OMD 控制台** 是唯一入口，内部分为概览、上下文、记忆、调用日志、后台日志；窄栏用顶部标签，宽栏或全屏用左侧导航。输入框下方信息栏与 BT 菜单可直接跳到对应分区。保留文件、终端、原生浏览器及第三方入口；资料阅读支持返回和 Escape。

| 入口 | 用途 |
| --- | --- |
| **概览** | Token、缓存命中、调用／失败、当前上下文、OMD 节省、Dream 额度；主执行与 OMD 后台分色趋势、组件用量与后台动态。 |
| **上下文** | 占用构成与替换后预计；预处理 → 中枢 → 替换状态、应用已准备结果、`/compact-p`／`/compact-f`、分段摘要与资料。 |
| **记忆** | 会话、项目、全局短记忆、摘要目录、整理作业与自动 Dream 设置。 |
| **调用日志／后台日志** | 每次模型调用（类型、模型、Token、耗时、状态），以及预处理、中枢决定、替换、压缩、主动异步、Dream 等后台记录；可搜索、筛选、分页。 |
| **任务证据** | 从 BT 菜单“查看任务证据”打开：需求摘录、状态与检查记录。 |
| 输入框下方信息栏 | 原生统计保持原读数，弹窗可跳到概览或调用日志；“上下文”项在整理中或有可替换结果时显示，可直接应用；Dream 作业进行时显示进度。 |
| 输入框 **权限菜单 → 记忆范围** | 首次发送前选择会话隔离、项目共享或全局记忆；开始后显示固定范围。 |
| **BT** | 随时调整待办／验证提醒，或打开任务证据。 |
| 模型与 Fast | 原生推理档、Ultra 及其三种子模式；有匹配 Subscriptions 能力时显示闪电。 |

侧栏保留原生搜索、菜单及插件行内操作，支持方向键、Home／End、Enter、Escape、Shift+F10。窄窗通过遮罩、选择会话或 Escape 收起；输入区按实际对话列宽适配，不用整个窗口宽度误判。系统或手动减少动态效果保留静态状态；主题属性与注册尊重第三方接管，卸载只撤回 OMD 自有贡献。

## 日常使用

标题右侧的 **会话总览** 集中显示输出内容、子智能体、后台进程、来源和电脑使用。展开子智能体可直接进入任一活跃成员的侧栏会话；点击标题进入分类总页，Workflow 的阶段面板和 Agent Team 的成员、任务板保留原有形式。彩色鲸鱼按代理身份保持一致；可续聊成员保留原生输入、排队、插入指令和停止能力。后台进程可查看输出和停止，来源可添加附件及打开已用资料。总览生效时，顶栏对应的原生重复入口收起。

总览依据完整会话记录展示，翻阅或分段加载历史不会改变已确认的来源、输出和工作流结果。子智能体状态显示当前回合结果；继续执行成功后，旧工作流中的失败记录仍保留。读取失败会显示具体原因，可点击“重试读取”；历史需要迁移时先打开对应会话。读取未完成时保留原生入口。

给助手目标、材料、范围与交付条件。多步骤工作可要求保留原始需求、建立待办、检查产物再交付。`todo_write` 管任务与锚点，`verify_link` 关联／执行／撤销证据；保留真实 tool、callId、命令、退出状态及起止时间。任务完成、运行结束、验证通过分开记录。

一批验证沿用开始时的工作目录，已完成的结果逐项保留，取消或后续执行失败不丢前面的结果。任务被编辑后，旧结果仍留在历史中，不会覆盖新任务。Python 的 pytest 与必要的脚本回退共用单项执行时限，失败测试不会按输出文字改用另一个运行器重跑。

**BT** 按会话保存：待办完成提醒独立开关，默认开启。第二项“任务验证”从左到右为 **关闭／默认／开启**，初始选中间的“默认”：保留 `verify_link` 和证据要求，不在收尾催促验证。“关闭”从该会话的 Native 工具列表和 PTC SDK 移除验证工具，停用证据要求、缺证据提醒与文字证据复核；普通 Todo 及已有证据保留。“开启”恢复完整验证机制，并在收尾检查缺证据和文字证据，可能多花时间与 Token。阻塞时可暂停本回合催促，不误勾完成。

“设置 → OMD → 智能体 → 任务验证默认档位”决定未在 BT 单独选择的会话所用档位；会话的显式选择独立保存。旧版已关闭验证提醒的会话迁移为“默认”，已开启的迁移为“开启”。切档会同步工具和界面，撤下已停用的验证催促；已发送的模型请求无法撤回，旧验证调用会被拒绝，已开始的验证命令允许结束并保留结果，尚未开始的检查不再执行。已有证据可继续在“查看任务证据”中读取，重新开启无需重建任务。

BT 仅在主会话显示并执行收尾提醒；普通、Workflow 和 Team 子代理保留其原有任务工具，不显示 BT、记忆范围、提示词优化、OMD 上下文／Dream 或模型／Ultra 设置。子代理仍可查看用量和耗时，聊天、权限及停止等操作遵循 DSH 原生限制；Fast 沿用订阅插件原生行为。

### 模型与工作模式

模型面板保留原生档位，另有 **Ultra**，包含 **Workflow / Agent Team / 自由** 三种子模式，首次使用默认自由。滑到 Ultra 后，点击面板顶部的 **Ultra** 按钮才展开子模式菜单，面板本身保持原尺寸。成功选择后在当前浏览器记住该选项，下次进入 Ultra 时复用，刷新后仍保留；已启用 Ultra 的会话保留自己的当前选择。Ultra 优先所选模型声明的 `xhigh`，没有则最高支持档；普通模式保留用户选择，未声明档位沿用提供方默认。Agent Team 由 DSH 原生开关和界面负责，未开启时选项隐藏；已保存的 Team 选择保留记忆并暂用自由。模式和子模式独立保存，切模型保持，选原生档或恢复默认关闭 Ultra 并记住子模式，不扩权。[Workflow](workflow.md)

保存准备期间若其他窗口已经修改模型，或所需的协作能力已不可用，本次保存会提示冲突或能力错误，不覆盖新的选择。保存结束后面板会核对当前状态；错误提示保留，可按当前选择重试，失败操作不会自动重放。运行中的 Ultra 策略仍在下一轮切换。

**Fast** 读取 Subscriptions 的能力和状态，支持 `codex`、`openai-codex` 别名；缺少匹配服务或模型不支持时隐藏。保存中防止旧轮询覆盖新选择，失败保留原状态并显示顶层可访问提示。偏好持久化、账号池和路由由实际 Subscriptions 版本负责；不宣称真实 OAuth、额度、priority 加速或付费通过。

### 原生 Tools 与 OMD-PTC

OMD 保留原生 Tools registry、SDK、调度、权限和取消，不整套替换。OMD-PTC 普通业务通过 `run_code`，仅匹配并采样核对的当前作用域保留四个后台直调控制：**`job_output`、`job_list`、`job_kill`、`runtime_status`**。嵌套 SDK、原生 preset 和第三方工具仍由宿主掌管，请求投影可逆，卸载保留他人包装。[适配边界](prompt-adaptation.md)

`run_code` 按当前 PTC 运行时的期限执行（宿主默认 120 秒、单次上限 600 秒），调用准备、内嵌工具、结果处理和进程收尾也有等待边界。超时或取消会返回明确错误；如果底层调用尚未真正收尾，会提示清理仍在进行，并拒绝同一会话的新业务工具调用，直到原调用结束；既有的直调任务控制仍可查询和停止作业。不要直接重试副作用未知的操作。程序启动前的原生人工审批继续等待用户决定，不计入程序执行期限。模式标签和选择器优先使用当前已加载会话的实时预设，切换聊天或重新连接时不会沿用过期列表摘要。

工具、验证命令、CodeGraph 与 Workflow 相对路径跟随宿主**当前执行目录**，不是永久锁在初始 cwd；项目身份与记忆归属仍保留。目录变化不绕过权限，也不把独立 Chat 变成共享项目。

## 上下文与记忆

**上下文优化**默认开启。在 **设置 → 上下文与记忆 → 上下文优化** 控制工具结果精简、重复读取引用、按需工具发现和原文保留。工具卡片点 **查看原文**，可按行号、关键词、开头／结尾翻阅；上下文页可导入原文档案。`context_view` 提供文件与网页视图，`code_search` 提供 16 种语法的 AST 模式搜索，CodeGraph 继续负责索引和代码关系。关闭优化保留已有原文与回查入口。[使用方式、统计与迁移](context-optimization.md#中文)

**多图请求修复**默认开启并选中 CMD，位于同一设置分组，平常折叠。展开后可添加已配置的渠道，再展开渠道设置图片数量上限、图片总大小上限和整理后保留数量；默认分别为 **20 张、10 MB、10 张**。大小按实际发送图片的 Base64 内容计算。每次请求前检查，超限时才批量停止发送较早的图片，原图与附件回查保留；后续未超限时不继续改写历史。保留数量是目标，大小限制可能要求更少，最新未读批次则始终保留；该批次本身超限时会提示分批读取或调整限制。规则适用于 OMD 及启用 OMD 增强的会话，关闭或移除渠道后恢复原有宿主限制。

图片整理与文本压缩分开触发，已有摘要和有效的压缩决定继续使用。整理会改变当次请求前缀，可能影响缓存；后台缓存预处理只使用符合当前图片限制的成功请求快照，不改写借用的前缀，没有合适快照时等待。使用 BC 时同步图片发送变化，不停用 Dream、档案或回查。

**上下文 → 上下文管理** 可按会话选择 OMD 或 Billion Context。当前适配 DSH **0.2.1-rc.2** 与原版 **billion-context 0.1.202**；在第三方功能安装并启用后选择 BC。只有自动压缩互斥，归档、Dream、任务、人格、原文与附件回查继续运行；显式手动操作会同步 BC，分支、侧问和回退保留各自边界。切换失败保留当前模式和原文，BC 不可用时明确报错。[兼容范围与使用方式](context-workflow.md#omd-与-billion-context)

后台保存事实摘要、具有原话依据的用户决定和详细资料，在安全请求边界替换历史表示。原话、文档、图片和附件保留，模型窗口仍有限。首次发送前在输入框的 **权限菜单 → 记忆范围** 选择，开始后锁定：

| 范围 | 自动注入与边界 |
| --- | --- |
| **会话隔离** | 不自动注入共享记忆，也不传播到项目／全局；明确回查仍可读取历史。 |
| **项目共享** | 同项目摘要／资料及已经完成的项目短记忆。 |
| **全局共享** | 更精简全局短记忆与分页项目目录，细节按需读取。 |

冷会话通过公共只读 inspection 查询，不为读取激活 Agent、新建账本或启动模型。保存范围前重新核对会话是否已经开始；读取失败保留错误、重试与原范围。

**上下文 → 异步压缩** 默认原版异步；主动异步由独立后台请求判断整理范围。主模型继续工作，后续请求只应用有效完成结果；切换取消旧请求，忽略迟到结果，原档案保留。`/compact` 应用已准备方案，`/compact-p` 将已准备片段改为摘要，`/compact-f` 调模型重新汇总，失败不删原文。[机制、预算与原文搜索](context-workflow.md)

`recall({search: 'original', query: '关键词'})` 明确搜索当前会话原始事件；跨会话显式加 `sessionId`。仅传 `query` 仍筛摘要目录。结果有界分页，按来源继续读取；回查是历史材料，不是新的执行指令。

**Dream** 提供整理会话、项目、全局和自动设置。全局可按大文件夹选择，空选择为全部，自定义 registry、嵌套项目与已删除历史目录使用同一归属规则。部分失败保留成功进度和首次来源截点，重试／重启继续未完范围；不发布残缺父汇总，不把失败作业当完成。自动默认关，开启默认每 60 分钟检查，手动／自动共用 200,000 Token／日额度。[Dream 详情](dream-memory.md)

关闭自动整理会暂停自动作业并阻止后续派发和迟到发布；已发出的请求仍可能产生用量。原作业可手动继续，复用保存进度且无需重新开启自动整理。停止后立即继续会等旧模型流收尾，界面提示和后台记录遵循实际作业状态。

频率默认适中：首批扣除近期保留和控制材料后，至少积累 48 条可摘要的有效事件；成功后按每 48 条新事件继续触发。最低文本量与工具往返完整性仍生效。空闲预处理默认关，启用默认等待 90 秒。**Oh My DSH → 上下文与记忆 → 记忆缓存模式** 默认关闭；开启后，原版及 Auto Compact 的预处理优先复用最近成功且可用的主请求模型与前缀。最新前缀超预算时保留并尝试同一路由的较小成功前缀；完整输入仍超预算时显示原因，保留原文，可提高预算或手动压缩。中枢仍使用原后台模型配置，已保存的预处理模型配置保留供关闭后使用；流水线显示摘要累计进度。缓存命中由提供方返回，后台仍有用量，不保证每次命中或省费。[缓存模式与预算](context-workflow.md)

## 提示词优化

输入框只保留 **✨**：悬停展开优化浮层，点击切换**每次都优化**，点亮表示已开启。键盘聚焦后按 ↓ 进入浮层，Esc 收起。浮层内可选 **轻润色、结构化、步骤规划**，填写额外要求／保存预设、手动开始或停止优化；支持撤销、重做、原稿和继续修改。每次发送前自动轻润色默认关，开启后每次额外调用当前模型，不读取附件正文或整段历史。结果生成时草稿／附件变化、停止、错误、超时、切会话都不自动发送。

每会话至多 20 个版本；当前页面内切会话保留未发送附件及优化记录，切换取消未完优化，返回不重放。发送未获宿主接纳时保留原稿、版本和待应用结果；若正在编辑另一份草稿，整份记录单独显示，不直接替换当前文本。查看保留记录不会截断已有的后续版本，待应用结果仍须明确应用。优化期间清空输入仍保留原稿供恢复，迟到结果不会自动写回或发送。刷新／关闭页面不保留这些附件与优化版本，文字草稿由宿主管理。偏好／要求预设保存在当前浏览器，同源标签同步，其他设备不自动同步。固定 MIT 模板及作者见[许可声明](../THIRD_PARTY_NOTICES.md)。

## 设置与保存

Oh My DSH 设置集中在一页，第三方功能进入独立子页。开关和选项改动立即保存；人格正文使用编辑区的保存按钮。保存失败会提示并恢复已存设置，人格编辑草稿保留。

宽窗口在内容左侧显示“本页目录”：点击跳到对应分组，滚动时高亮当前位置；点击“高级”会自动展开。可用宽度较小时，目录自动收为顶部的分组菜单。进入第三方功能或来源清单时隐藏目录，返回后恢复原滚动位置；控制台中的 Dream 设置快捷入口也会定位到对应设置。

| 设置分组 | 常用内容 |
| --- | --- |
| 功能 | Workbench、扩展管理、智能交互回答、智能体预设、代码理解与提示词优化开关；第三方功能入口 |
| 人格 | 全局预设、四个模块、人格文件与会话人设 |
| 上下文与记忆 | 多图请求修复、上下文优化、后台预处理、中枢、缓存模式、Auto Compact、默认记忆范围与 Dream |
| 后台模型／全局背景 | 后台调用的模型路由与手写固定背景 |
| 智能体 | 系统提示词风格、会话入口开关、运行状态、预算提示、后台等待和任务约束前置 |
| 关于／高级 | 版本与功能更新；高级参数以及“其他”中的历史加载条数 |

**系统提示词风格**位于智能体分组，保留 OMD 默认、DSH 原生、Codex、Cursor、Pi、Grok、ZCode 七个选项，默认 OMD 默认。**启用会话提示词风格**默认关闭；开启后，OMD／OMD-PTC 主会话权限菜单才显示选择入口。未单独选择时跟随全局，关闭开关使用全局并保留会话选择，重新开启恢复；修改从下一回合生效。人格、工具、任务和记忆保持各自功能。[来源与适配](prompt-adaptation.md)。

**人格预设**选择全局默认人格，内置默认、超频和精算。超频充分展开有价值的依据与细节；精算减少重复与无效表达，保持交付质量。下方的**高级**默认折叠，集中管理多个人设：新建、复制、改名、更新、删除及文件导入导出。编辑对象独立于全局选择；保存编辑不会自动切换全局人格。删除正在使用的全局预设时，其完整内容保留为“自定义”。内置预设可复制后修改。

多个窗口同时编辑时，过期的保存会停止并显示最新人格设置，保留本地草稿供核对后重试；被另一处删除的人设草稿可另存为新预设。

每个人设包含**身份与人格、语言风格、沟通方式、回答呈现**四个模块；后三项可继承默认内容，取消继承后留空表示不添加该模块的偏好。人格不会替换实际环境、权限、工具协议、任务控制或记忆处理规则。

点击**复制创作提示词**，把内容交给 AI 并描述想要的人格；AI 按所附格式生成 JSON 文件后，用**导入人格文件**创建并选用新预设。同名文件会自动改名，不覆盖已有预设；格式错误会指出问题。**导出人格文件**可保存当前编辑内容，供备份、分享或再次交给 AI 修改。

**启用会话人设**默认开启，OMD 与 OMAA 主会话的权限抽屉会显示**会话人设**，可继承全局、选择指定人设或关闭人格，后续模型请求生效。会话开始后仍可切换，各会话单独保存。关闭此功能时统一使用全局人格，重新开启后恢复各会话的选择；所选预设被删除时回退全局并显示提示。子会话不显示此入口。升级保留已明确关闭的设置；已移除的内置人格全局选择回退为默认，会话选择回退全局，自定义人格内容保留。

全局背景由用户手写维护，冲突时 **读取最新版本** 比较后合并或采用再保存，读取不覆盖草稿。Dream 不改手写背景。

Glyph 等五套主题与 DSH 原生外观可选，29 套配色、背景独立，支持分区颜色、字体字号、Logo／标题和减少动态效果。[外观指南](skins.md)

## 监控

**OMD 控制台** 的概览、调用日志与后台日志按本会话／全部会话及时间查看。持久 SQLite 账本记录实际调用身份、主会话／真实子代理／后台归因、路由、状态、错误、用量和耗时，支持日期／模型／组件筛选、趋势、分组和分页详情。写失败保留诊断，不拖垮模型调用。

**`≥` 是已知下界，不是完整消耗。** 输入／缓存／输出缺失不当零，无用量回执保留调用状态，不画零趋势；缓存命中率只在信息完整且一致时计算。上下文估算不是提供方账单，累计调用用时含并行，不是墙钟时间。历史累计缺少归因时单列，不摊到日期或模型。[完整统计口径](monitoring.md)

## CodeGraph

内置 1.6.0，默认准备当前代码目录的 `.codegraph/`，不需全局 CLI。直接问“登录请求经过哪些函数？”；查询使用当前执行目录，向上查最近索引，其他仓库通过 `projectPath` 显式指定。首次查询等待准备，失败可重试，普通文件／搜索工具继续可用。

代码理解工具准备失败时，设置中的「代码理解」保留原始原因，新建聊天不会反复启动同一次失败的准备。修复环境后点击「重新准备」，或关闭后重新开启。已断开的查询连接会在下一次查询前重新建立；已经失败的查询不会自动重跑。

连接监听改动，空闲释放，下次补齐；关闭／卸载停止自有进程，保留项目索引。索引不在 DSH 会话备份中，通常不提交。源码结果进入所选模型请求；结构不能替代编译／测试。明确只读、禁止索引的目录不得自动准备。

## 扩展功能与第三方

在 **设置 → Oh My DSH → 功能** 开启 DeepSeek 工作台、智能交互回答和智能体预设；社区功能集中在 **第三方** 子页。每行提供简短介绍和开关：首次打开自动安装并启用，关闭只停用，配置和数据保留；版本、来源、检查更新与卸载放在折叠的“详情”中。btw 与撤回已内置，不再重复列入推荐。

安装和启停使用当前 profile 的原生管理器，仍按完整宿主版本、固定发行包与 SHA-256 校验；不兼容或需额外配置的条目会说明原因。自动更新默认关闭，仅检查已安装并开启的功能，不跨宿主、不自动批准安装脚本或重启。请求超时后重新读取实际状态，不重复盲装。

排队或预检结束后，更新会在移除／安装前重新核对当前状态。关闭自动更新、开始任务或停用功能会阻止尚未开始的自动更新；手动更新期间若安装版本或启用状态改变，保留当前选择并提示重新操作。OMD 自更新同样重新核对任务、已知发布信息和原生安装状态；“仍然安装”不能跳过这些条件。

当前源码的 **设置 → Oh My DSH → 关于 → 插件安装预检** 默认开启。经过当前进程原生插件管理器的安装、更新和启用，会先在临时 DSH 中检查加载、输入入口和设置界面。原市场保持打开，通过后自动继续；未通过时可取消、复制 AI 修复信息，或选择“仍然安装”。继续只跳过这次预检，宿主版本、脚本授权及安装规则仍由原生管理器执行。关闭开关后，新请求沿原流程执行。

预检一次只运行一个任务，优先复用已有浏览器及原生包管理器缓存，不自动下载浏览器，不复制会话、账号凭据或第三方私有数据。准备阶段最多 120 秒，启动检查最多 45 秒；缺少浏览器、外部配置或达到资源预算时显示“预检未完成”，不会标成兼容。进程退出后删除本次临时目录；异常退出遗留的自有目录在下次启动或检查时回收。失败信息只在当前操作内保留，五分钟未选择会取消，不累计报告或截图。原生安装所需的共享缓存保留。

目前接入的是运行中宿主的原生管理器，包括走该服务的原生插件页、工具调用和桌面 dsh-market。绕过该服务的 Web 市场、外部 `dsh plugin`／npm／pnpm 命令和手工修改目录，尚未自动接入；也没有安装宿主启动前的全局拦截器。[接入与验证范围](plugin-compatibility.md#推荐更新与数据)

**IUI、OMAA、Subscriptions、Intent 均为独立项目**，使用各自匹配宿主的构建。OMD 保留其入口、工具、配置与用户数据，不接管独立插件的账号和业务功能。[插件共存边界](plugin-compatibility.md)

**DeepSeek Workbench** 内置默认启用，可打开网页聊天、开放平台、导入可提取历史为原生会话；原网页保留，由用户发送下一条。内置网页、持久登录与下载需要匹配的宿主桥接。[使用说明](deepseek-workbench.md)

**扩展管理** 内置默认启用，在 **插件** 页增加 Skill、MCP、指令、命令、Hooks 五个标签页：开关 Skill、管理 `~/.dsh/mcp.json` 中的 MCP 服务器与单个工具、编辑 AGENTS.md／CLAUDE.md、用 Markdown 模板定义 `/命令`、配置 Claude Code 格式的 Hooks。[使用说明](extensions.md)

## 侧问与回合回滚

### 临时侧栏聊天

在输入框执行 `/侧栏`，使用当前所选模型打开独立的临时文字聊天；不继承主聊天上下文，消息仅存内存，关闭时停止回复并清空。临时文字聊天不执行工作区工具。`/侧栏（网页版）` 使用 DeepSeek 网页账号打开临时侧栏，关闭时删除本次官网会话；清理失败保留面板并允许重试。两种入口都保留主聊天当前位置。

`/btw 问题` 使用内置的 [DSH BTW](https://github.com/gulagala001/dsh-btw)，在主输入框上方打开原生旁聊弹窗。沿用主会话快照与模型，支持历史、追问和独立停止；关闭弹窗不终止回答，停止按钮只取消旁聊并保留已收到的文字；只有明确完成且未截断的回答进入追问上下文，失败或中断后可手动重试。每个主会话最近 20 次旁聊仅保存在当前窗口内存，刷新后清空；不执行工具、不写入主对话或 Dream。维护者：gulagala001。[作者与许可](../THIRD_PARTY_NOTICES.md#bundled-dsh-btw)

OMD 内置 `@gulagala001/dsh-undo-plugin`。 会话空闲时连按两次 Esc，或输入 `/rewind`，可在输入框上方打开回退列表；`/undo` 撤销上一次撤回，均需确认。运行中双击 Esc 保留停止行为。用户消息的复制按钮旁提供撤回入口，确认后原地撤回该消息及之后的对话，不创建分支会话；已有检查点时同时恢复工具造成的文件改动，没有备份的旧消息会明确提示仅撤回对话。原文字、图片和文件回填输入框，可用「撤销撤回」恢复此前的对话与文件。恢复前核对外部改动，冲突时保留现场和备份。独立插件与本版 OMD 共装时复用同一服务与按钮，停用其中一方后由仍启用的一方提供功能；不要同时启用其他修改会话历史的 rewind 插件。旧 Turn Rewind 推荐和专用界面兼容层已移除，已有第三方安装与数据保留。

## 数据与维护

回退、撤销回退及失败恢复使用同一历史截点还原任务清单、原话节选和验证证据；工具、任务栏、上下文及完成检查读取同一份原生任务记录。恢复消息不再作为新的用户要求重复编号，也不会解除本轮暂停提醒；已有原话编号保留，跳过恢复副本后可能不连续。证据只是恢复历史结果，不代表重新验证。没有事件截点的旧消息快照不会推断或覆盖任务记录。

工具执行前，回退备份维护和工作区锁各最多等待 30 秒；超时返回错误，不放行未取得锁的工具。取消可退出尚未开始的备份排队；已开始的备份继续收尾，正在恢复的工作区拒绝新工具。这适用于 Standard 与 PTC 等所有使用该回退服务的模式。

回退备份的 2 GiB 是空闲清理软目标，另有默认 4 GiB 的备份内容与索引写入上限；多实例共用写锁核对实际占用，已有恢复记录不会为满足上限被强删，恢复元数据及整理临时副本另计。工具前后会捕获整个可扫描工作区，大目录内未变化的文件也可能暂存后再释放。短操作不会推迟已排定的清理；备份写入、整理和恢复临时文件均检查至少 512 MiB 可用空间。空间不足时停止新增备份、保留正常工具执行，并明确记录该段文件变化无法安全回退；中断恢复保留事务和备份。不要在恢复期间手动删除 `$DSH_HOME/rewind-plus/v1`。

人格、撤回备份、工作流和网页导入分别保留自己的数据。仅复制 `oh-my-dsh/` 不覆盖所有功能；请按[插件数据归属](architecture.md#数据由对应功能保留)一并备份。

数据使用实际 `DSH_HOME`（Web 默认用户目录 `.dsh`），OMD 在 `oh-my-dsh/`；源码默认仓库 `data/dsh/`。完整备份 profile、凭据、会话、附件、上下文和记忆。Dream 数据在 `dream-v1/memory.sqlite`，监控在 `monitor-v1/usage.sqlite`，旧自动记忆只读保留；外部项目／索引另备份。停用／卸载不清资料。
