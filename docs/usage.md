## 安装到现有 DSH（推荐）

公开固定配对为 DSH `0.2.1-alpha.1`／OMD `0.2.1-alpha.1.omd.0.10.0`，或 DSH `0.2.0-rc.2`／OMD `0.2.0-rc.2.omd.0.10.0`。本地 0.17 没有公开安装 URL；按[首页固定包表](../README.md#quickstart)选择完整匹配，不用 `latest`，不将 alpha.2 包改 metadata 装到 rc.2。

以下只演示公开 **alpha.1 Web**：Node.js ≥22.19、Git、固定版本的 pnpm 11.23.0，Windows 使用 PowerShell 7。先结束任务、停止服务并备份实际 `DSH_HOME`，保留原 profile、端口及启动方式，在同一数据目录执行：

```sh
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile web add https://github.com/gulagala001/oh-my-dsh/releases/download/v0.2.1-alpha.1.omd.0.10.0/trisoul_x-0.2.1-alpha.1.omd.0.10.0.tgz
npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 --profile web
```

打开本次启动打印的完整登录链接。新 Web 默认 3080，已有环境沿用原端口；自定义 profile 替换 `web`。桌面通过应用内或自带 CLI 安装与实际完整宿主匹配的公开包，属于独立 `desktop` profile，普通 Web CLI 不能代替它。固定发行的详细步骤以[对应 tag 文档](https://github.com/gulagala001/oh-my-dsh/tree/v0.2.1-alpha.1.omd.0.10.0/docs)为准。

默认 preset 为 Oh My DSH，包含完整文件／命令访问、关闭执行审批；**profile 显式覆盖优先**。旧会话保留原 preset，不自动转换。当前重构不更新或重启工作 DSH。

npx --yes @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile web remove trisoul_x

## 无项目聊天

鼠标移到已选工作区标签，点 **×** 取消。草稿、附件、模型和权限保留，可以重新选择工作区。首次发送才在 DSH 所在电脑创建独立目录，默认 **Documents/DSH/日期/首条消息名**，重名编号；刷新、重启或继续复用原目录，另开聊天才建新目录。这些目录不注册成工作区，聊天显示在“未分组”。

**自动文件目录不是 Dream 项目。** Chat 及未另行加入真实工作区的后代保持隔离；改默认保存根目录、改执行目录或删除原目录，不会把历史 Chat、旧 Dream 作业误纳入共享。归属异常暂时隔离共享并保留诊断，基础聊天继续。用户明确加入真实原生工作区后，按其归属与所选范围处理。[Dream 隔离](dream-memory.md)

权限显示“自定义”时先选权限预设；同步失败保留草稿并提示重试。文件访问权限与记忆共享范围是两件事。

## 界面与入口

右侧栏引导页的 **OMD 控制台** 是唯一入口，内部分为概览、上下文、记忆、调用日志、后台日志；窄栏用顶部标签，宽栏或全屏用左侧导航。输入框下方信息栏与 BT 菜单可直接跳到对应分区。保留文件、终端、原生浏览器及第三方入口；资料阅读支持返回和 Escape。

| 入口 | 用途 |
| --- | --- |
| **概览** | Token、缓存命中、调用／失败、当前上下文、OMD 节省、Dream 额度；主执行与 OMD 后台分色趋势、组件用量与后台动态。 |
| **上下文** | 占用构成与替换后预计；预处理 → 中枢 → 替换状态、应用已准备结果、`/compact-p`／`/compact-f`、分段摘要与资料。 |
| **记忆** | 会话、项目、全局短记忆、摘要目录、整理作业与自动 Dream 设置。 |
| **调用日志／后台日志** | 每次模型调用（类型、模型、Token、耗时、状态），以及预处理、中枢决定、替换、压缩、主动异步、Dream 等后台记录；可搜索、筛选、分页。 |
| **任务证据** | 从 BT 菜单“查看任务证据”打开：需求摘录、状态与检查记录。 |
| 输入框下方信息栏 | 原生统计保持原读数，弹窗可跳到概览或调用日志；“上下文”项在整理中或有可替换结果时显示，可直接应用；Dream 作业进行时显示进度。 |
| 模型旁 **范围／BT** | 首次发送前选择范围，随时调整提醒。 |
| 模型与 Fast | 原生推理档、Ultra 及其三种子模式；有匹配 Subscriptions 能力时显示闪电。 |

[![OMD 控制台概览](images/release/monitor.jpg)](monitoring.md)

侧栏保留原生搜索、菜单及插件行内操作，支持方向键、Home／End、Enter、Escape、Shift+F10。窄窗通过遮罩、选择会话或 Escape 收起；输入区按实际对话列宽适配，不用整个窗口宽度误判。系统或手动减少动态效果保留静态状态；主题属性与注册尊重第三方接管，卸载只撤回 OMD 自有贡献。

## 日常使用

标题右侧的 **会话总览** 集中显示输出内容、子智能体、后台进程、来源和电脑使用。展开子智能体可直接进入任一活跃成员的侧栏会话；点击标题进入分类总页，Workflow 的阶段面板和 Agent Team 的成员、任务板保留原有形式。彩色鲸鱼按代理身份保持一致；可续聊成员保留原生输入、排队、插入指令和停止能力。后台进程可查看输出和停止，来源可添加附件及打开已用资料。总览生效时，顶栏对应的原生重复入口收起。

给助手目标、材料、范围与交付条件。多步骤工作可要求保留原始需求、建立待办、检查产物再交付。`todo_write` 管任务与锚点，`verify_link` 关联／执行／撤销证据；保留真实 tool、callId、命令、退出状态及起止时间。任务完成、运行结束、验证通过分开记录。

**BT** 按会话保存：待办提醒默认开启，验证提醒默认关闭；后者检查缺证据或文字证据，可能多花时间与 Token。关闭不影响任务工具；阻塞时可暂停本回合催促，不误勾完成。

BT 仅在主会话显示并执行收尾提醒；普通、Workflow 和 Team 子代理保留其原有任务工具，不显示 BT、记忆范围、提示词优化、OMD 上下文／Dream 或模型／Ultra 设置。子代理仍可查看用量和耗时，聊天、权限及停止等操作遵循 DSH 原生限制；Fast 沿用订阅插件原生行为。

### 模型与工作模式

模型面板保留原生档位，另有 **Ultra**，包含 **Workflow / Agent Team / 自由** 三种子模式，默认自由。Ultra 优先所选模型声明的 `xhigh`，没有则最高支持档；普通模式保留用户选择，未声明档位沿用提供方默认。Agent Team 由 DSH 原生开关和界面负责，未开启时选项隐藏；已保存的 Team 选择保留记忆并暂用自由。模式和子模式独立保存，切模型保持，选原生档或恢复默认关闭 Ultra 并记住子模式，不扩权。[Workflow](workflow.md)

**Fast** 读取 Subscriptions 的能力和状态，支持 `codex`、`openai-codex` 别名；缺少匹配服务或模型不支持时隐藏。保存中防止旧轮询覆盖新选择，失败保留原状态并显示顶层可访问提示。偏好持久化、账号池和路由由实际 Subscriptions 版本负责；不宣称真实 OAuth、额度、priority 加速或付费通过。

### 原生 Tools 与 OMD-PTC

OMD 保留原生 Tools registry、SDK、调度、权限和取消，不整套替换。OMD-PTC 普通业务通过 `run_code`，仅匹配并采样核对的当前作用域保留四个后台直调控制：**`job_output`、`job_list`、`job_kill`、`runtime_status`**。嵌套 SDK、原生 preset 和第三方工具仍由宿主掌管，请求投影可逆，卸载保留他人包装。[适配边界](prompt-adaptation.md)

工具、验证命令、CodeGraph 与 Workflow 相对路径跟随宿主**当前执行目录**，不是永久锁在初始 cwd；项目身份与记忆归属仍保留。目录变化不绕过权限，也不把独立 Chat 变成共享项目。

## 上下文与记忆

后台保存事实摘要、具有原话依据的用户决定和详细资料，在安全请求边界替换历史表示。原话、文档、图片和附件保留，模型窗口仍有限。首次发送前选范围，开始后锁定：

| 范围 | 自动注入与边界 |
| --- | --- |
| **会话隔离** | 不自动注入共享记忆，也不传播到项目／全局；明确回查仍可读取历史。 |
| **项目共享** | 同项目摘要／资料及已经完成的项目短记忆。 |
| **全局共享** | 更精简全局短记忆与分页项目目录，细节按需读取。 |

冷会话通过公共只读 inspection 查询，不为读取激活 Agent、新建账本或启动模型。保存范围前重新核对会话是否已经开始；读取失败保留错误、重试与原范围。

**上下文 → 异步压缩** 默认原版异步；主动异步由独立后台请求判断整理范围。主模型继续工作，后续请求只应用有效完成结果；切换取消旧请求，忽略迟到结果，原档案保留。`/compact` 应用已准备方案，`/compact-p` 将已准备片段改为摘要，`/compact-f` 调模型重新汇总，失败不删原文。[机制、预算与原文搜索](context-workflow.md)

`recall({search: 'original', query: '关键词'})` 明确搜索当前会话原始事件；跨会话显式加 `sessionId`。仅传 `query` 仍筛摘要目录。结果有界分页，按来源继续读取；回查是历史材料，不是新的执行指令。

**Dream** 提供整理会话、项目、全局和自动设置。全局可按大文件夹选择，空选择为全部，自定义 registry、嵌套项目与已删除历史目录使用同一归属规则。部分失败保留成功进度和首次来源截点，重试／重启继续未完范围；不发布残缺父汇总，不把失败作业当完成。自动默认关，开启默认每 60 分钟检查，手动／自动共用 200,000 Token／日额度。[Dream 详情](dream-memory.md)

频率默认适中，空闲预处理默认关，启用默认等待 90 秒。后台可跟随或单独配模型，仍有用量，不保证省费。

## 提示词优化

点星星选 **轻润色、结构化、步骤规划**，可填额外要求／保存预设，确认后发送；支持撤销、重做、原稿和继续修改。自动发送前轻润色默认关，开启后每次额外调用当前模型，不读取附件正文或整段历史。结果生成时草稿／附件变化、停止、错误、超时、切会话都不自动发送。

每会话至多 20 个版本；当前页面内切会话保留未发送附件及优化记录，切换取消未完优化，返回不重放。发送未获宿主接纳时保留原稿和版本；若正在编辑另一份草稿，保留版本单独显示，不直接替换当前文本。刷新／关闭页面不保留这些附件与优化版本，文字草稿由宿主管理。偏好／要求预设保存在当前浏览器，同源标签同步，其他设备不自动同步。固定 MIT 模板及作者见[许可声明](../THIRD_PARTY_NOTICES.md)。

## 设置与保存

设置分常用、基础组件、模型与身份、实验性功能、高级和全局背景。普通改动点 **保存设置**，组件开关立即保存；只提交修改字段，保存期间的新输入保留，需再次保存。迁移期间读取动态旧配置，不让旧 overlay 吞掉新值。

人格可选默认、硬邦邦、软乎乎、自定义、关闭；预览／复制到自定义，切换不删已保存内容，下一主请求生效。全局背景由用户手写维护，冲突时 **读取最新版本** 比较后合并或采用再保存，读取不覆盖草稿。Dream 不改手写背景。

五种主题、28 套配色、背景独立，支持分区颜色、字体字号、Logo／标题和减少动态效果。[外观指南](skins.md)

<a id="状态后台任务与阻塞处理"></a>

运行状态／预算默认关，后台优化默认开，CoT 前置默认开，CFR 默认关；下一请求生效，不改变原权限。[后台选项](runtime-state-background.md)

## 监控

**OMD 控制台** 的概览、调用日志与后台日志按本会话／全部会话及时间查看。持久 SQLite 账本记录实际调用身份、主会话／真实子代理／后台归因、路由、状态、错误、用量和耗时，支持日期／模型／组件筛选、趋势、分组和分页详情。写失败保留诊断，不拖垮模型调用。

**`≥` 是已知下界，不是完整消耗。** 输入／缓存／输出缺失不当零，无用量回执保留调用状态，不画零趋势；缓存命中率只在信息完整且一致时计算。上下文估算不是提供方账单，累计调用用时含并行，不是墙钟时间。历史累计缺少归因时单列，不摊到日期或模型。[完整统计口径](monitoring.md)

## CodeGraph

内置 1.6.0，默认准备当前代码目录的 `.codegraph/`，不需全局 CLI。直接问“登录请求经过哪些函数？”；查询使用当前执行目录，向上查最近索引，其他仓库通过 `projectPath` 显式指定。首次查询等待准备，失败可重试，普通文件／搜索工具继续可用。

连接监听改动，空闲释放，下次补齐；关闭／卸载停止自有进程，保留项目索引。索引不在 DSH 会话备份中，通常不提交。源码结果进入所选模型请求；结构不能替代编译／测试。明确只读、禁止索引的目录不得自动准备。

## Computer Use

新版 OpenCU `2.0.0` 已默认内置，替换旧 1.3.0 过渡快照。提供真实浏览器与原生目标发现、观察、后台优先输入、监看和批注。完整 UI 依赖匹配 Host／Client／preload 适配，不是 stock DSH 仅安装插件即可自动获得。[使用指南](computer-use.md) · [接入边界](plugin-compatibility.md#opencu)。

### 开始使用

确认匹配构建与权限后，直接让助手打开网页、检查页面或操作已连接应用。内置浏览器、扩展接入和自动化浏览器分开选择；浏览器扩展首次需用户 Allow。查看不等于接管，关闭预览不等于停止；继续前观察实际状态。[操作与批注](computer-use.md)；旧 0.10 用户仍看[固定 tag 文档](https://github.com/gulagala001/oh-my-dsh/blob/v0.2.1-alpha.1.omd.0.10.0/docs/usage.md#computer-use)。

### 平台与运行条件

任务、主题、上下文与记忆面向匹配 DSH 的 Windows、macOS、Linux，不依赖原生桌面控制。电脑操作的系统依赖与权限见[电脑与浏览器](computer-use.md)。

## 推荐插件页面显示

推荐页列用途、原作者、来源、完整宿主、固定工件、SHA-256 和状态。安装由当前 profile 原生管理器执行，未知组合／缺工件／未发布目标不假装可装。跨宿主切换明确手动选择并保留数据，自动更新不跨宿主、不自动批准脚本、不重启。推荐写入与响应体有 10 秒上限，回执丢失回读状态，不永远卡在写入，不盲目重复安装。

**IUI、OMAA、Subscriptions、Intent 均为独立项目**，使用各自匹配宿主的构建。OMD 保留其入口、工具、配置与用户数据，不接管独立插件的账号和业务功能。[插件共存边界](plugin-compatibility.md)

**DeepSeek Workbench** 内置默认启用，可打开网页聊天、开放平台、导入可提取历史为原生会话；原网页保留，由用户发送下一条。内置网页、持久登录与下载需要匹配的宿主桥接。[使用说明](deepseek-workbench.md)

## 侧问与回合回滚

`/btw 问题` 复用最近已发出的主请求前缀，主任务运行时显示答案，不执行工具；`/btw cancel` 只停止侧问。Codex 订阅侧问在模型适配器发送处沿用主会话缓存键，守卫与记录仍属于独立子会话；缓存读取显示渠道真实用量，未披露不按零计，不保证每次服务端命中。冷启动先等待主请求建立可核对前缀，不纳入项目／全局 Dream。原作者 JasonQQ；Turn Rewind 原作者 Anionex，固定 `0.3.9` 在 alpha.1 被原生拒绝，请按插件要求匹配宿主版本，不绕过版本门禁。[作者与许可](../THIRD_PARTY_NOTICES.md)

已安装并启用 Turn Rewind 时，OMD 保留其原版按钮、预览与确认弹窗，按当前观看会话的真实回合首条用户消息匹配；该消息被宿主归类为 steering 时也可显示。延迟加载、消息行重挂和节点原位更新会重新匹配，后续回合内追加消息不冒充可回退点；没有文件检查点时仍由原弹窗提供「只回溯消息」。

## 数据与维护

数据使用实际 `DSH_HOME`（Web 默认用户目录 `.dsh`），OMD 在 `trisoul-x/`；源码默认仓库 `data/dsh/`。完整备份 profile、凭据、会话、附件、上下文和记忆。Dream 数据在 `dream-v1/memory.sqlite`，监控在 `monitor-v1/usage.sqlite`，旧自动记忆只读保留；外部项目／索引另备份。停用／卸载不清资料。

## 版本与更新提醒

面板区分当前和远端版本，显示进度、错误与待重启；绿点普通更新，红点必要修复。检查不调用模型或上传会话；失败不当最新版。本地 `unpublished` 不进入公开更新计算，安装前再次拒绝。历史版本按版本规则排序和去重，不凭发布日期或旧最高数字猜新包；宿主另行更新。
