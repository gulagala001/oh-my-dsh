# OMD 与其他插件共用

[English](plugin-compatibility_EN.md) · [目录](README.md) · [安装升级](upgrade.md) · [推荐插件](usage.md#推荐插件页面显示) · [申请适配](plugin-submissions.md)

先查 DSH、OMD、第三方插件的完整版本。通过安装检查不表示账号业务、界面和生命周期全部实测。

OMD 使用原生管理器、工具、技能、作用域。兼容改进保留全功能，不靠跳过检查或关闭增强宣称共存。

## 安装和更新其他插件

1. 推荐页查用途、作者、固定来源、宿主、状态；未发布／缺校验可能不可装。
2. 当前 profile 原生安装，桌面应用内或自带 CLI。
3. 完整重启，打开插件入口，核对工具／技能／设置。
4. 账号业务按插件单独验证；安装启用不等于额度、OAuth、付费通过。

自动更新默认关，只管已装已启用核验发行，不跨宿主自动换包。升级先查全套 SDK 与固定构建，不放宽 peer 或复制其他宿主依赖。

## OpenCU 独立插件与 OMD 内置集成

OMD 已含 OpenCU，无需另装；只需操控可[独立安装 OpenCU](https://github.com/gulagala001/opencu)，不强制 OMD。

最新本地实现已测共同安装两种加载顺序，结论限实际配对，不等于任意版本兼容，也不等于 GitHub OMD 已含最新修复。公开组合按对应发行文档。

## 常见插件边界

| 插件 | 核对事项 |
| --- | --- |
| OMAA | 独立预设，基础与可选增强分别判断，换宿主要对应构建。 |
| Subscriptions | 固定 OMD 适配包，账号/Fast/额度/付费业务另查。 |
| Intelligent UI | 可选，明确提交才续对话，固定发行／校验齐全才可装。 |
| OpenDesign | 单独准备其技能／设计工具，OMD 不替代账号条件。 |
| Turn Rewind `0.3.9` | alpha.1 原生拒绝，rc.2 接受；不绕过。 |
| Status Rotator 等标准插件 | 完整来源／版本，实际查界面、启停、卸载。 |
| Blender 等开发注入 | 未标准打包时按项目连接和注入说明。 |

以目录与独立发行说明为准，不从一次共装推断所有版本平台。

## 共存结果能说明什么

代表插件在原版 DSH 与 OMD 对照过固定版本、两个加载顺序、启停、重启、卸载、工具／技能／界面。后续 alpha.2、本地集成限其对应范围，不继承旧包全部结果。

隔离 Web 用受控模型、虚构材料，不代表真实订阅、OAuth 全业务、全部第三方或 Windows 原生桌面通过；本轮 Windows 未实机。原生拒绝不算成功安装。

插件可能只给特定预设工具／技能，standard 可见不保证 OMD 可见。

卸载保留会话、草稿、附件和设置，不代表缺预设旧会话可运行；可能需恢复 OMD／OMAA 等预设。新 standard 可用不证明旧会话已转换。

可选增强失效应隔离，基础可用；不确定组合保留诊断，恢复匹配版本或停涉事组件。
