# OMD 0.15.0 整合候选：原生工作台与执行监控

本候选未正式发布，配对 DSH **0.2.1-alpha.2**，内置 **OpenCU 1.6.0**。本次更新本机 Web 服务；公开安装入口继续指向已发布版本。rc.2 和 alpha.1 保留原有独立候选，不使用本次 alpha.2 包。

整合 0.11 至 0.14 的插件共存、宿主适配、Chat 隔离、原生前端、右侧内容标签页及应用预览。工作台从宿主新标签页打开任务、上下文、Dream 和监控，保留第三方入口与已访问页面的阅读状态。

[执行监控](monitoring.md)分为概览、用量和上下文：支持时间与会话范围、路由和状态筛选、趋势、分页调用详情及预算与运行资源。实际回执写入本地元数据账本，未知用量与取消单独显示；历史缺失不补造。

修复 OMAA 等外观拥有者启用时，用量折叠按钮不能隐藏原生统计的问题。保留独立 Intelligent UI、OMAA、Subscriptions 的配置与生命周期。

验收以整合提交上的构建、定向回归、八场景真实宿主基线和真实 Web 点击为准。受控模型不证明真实模型质量，macOS Web 结果不外推为 Windows、Linux、官方桌面或全部扩展／原生应用路径通过。
