# OMD 0.1.7-rc.2.17

发布候选，尚未发布。配套 DSH 0.1.7-rc.2，继续内置 OpenCU 1.1.7。

本版新增 Codex 风格的模型与推理面板，以及基于原生 Workflow 的 Ultracode。输入框可搜索模型、拖动思考档位或恢复默认；Ultracode 是最后一档，模式与实际推理参数分别保存。没有 Fast。

开启后，实质任务使用工作流组织实现、审查与验证，完整编写参考自动加入当前请求。普通最高推理档位仍可单独选择；切换模型时按其声明的能力映射最高档，不向 API 发送虚构档位。蓝紫渐变、粒子、光晕、拖动放大和刻度过渡兼顾明暗主题、窄屏、触屏与减少动态效果。

Workflow 新增脚本保存、命名调用、单层嵌套、最长成功前缀续跑、独立 worktree、原生 agent preset，以及子代理独立模型／推理设置。共享输出目标、后台 Jobs、取消和恢复沿用宿主生命周期。子代理可直接实现代码；有改动的 worktree 会保留，不自动合并。详见 [Workflow 指南](workflow.md)。

## 与参考实现的边界

四条提醒和完整参考固定对照 CC 2.1.265、2.1.266、2.1.280 的本地实际请求。DSH 用完整系统提示词段装配，消息位置与 CC 不同；代理类型使用 DSH preset，结构化输出以宿主支持的 schema 子集为准，推理参数依模型能力映射。

DSH 没有 `/clear` 命令，使用既有上下文压缩与会话管理。停用插件后，OMD preset 会话需重新启用插件后续跑；普通 DSH 会话和原生历史读取保持可用。模型遵循工作流策略的质量受模型能力影响，不能由提示词或协议测试保证。

## 升级

对应 Release 发布后，在 OMD 版本面板更新，或在当前环境的原生插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.17`，随后完整重启应用与 Host。桌面更新使用桌面插件管理器，不使用 CLI 修改 `desktop` profile。

保留原有模型、会话、插件与外观设置。模式记录位于插件的会话存档中，原生会话日志只保留宿主支持的事件类型。
