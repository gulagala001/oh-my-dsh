# 运行状态、后台任务和 Todo 阻塞处理

在 **设置 → Oh My DSH → 实验性功能** 中开启。运行状态和后台优化默认关闭，保存后从下一次模型请求生效；已有会话同样适用。CoT 前置和 CFR 也在此页。

## 运行状态

状态与 Todo 共用同一条投递、压缩和回放链。状态发生实质变化时更新，不按秒钟刷屏，也不因时间流逝唤醒模型。没有任务时可以单独提供状态，不会强迫创建待办。

内容包括采集时间、本回合经过的时间、当前保留内容的 token 估算、上下文记录的表示方式、最近确认的模型窗口及已注册后台任务。估算不包含尚未入场的输入和新系统装配，窗口不代表剩余额度；不会生成任务进度百分比、截止时间或虚构预算。

`runtime_status({})` 可查询新鲜状态。任务的“完成”“已投递输出”和“验证成功”含义不同，不能相互代替。关闭自动状态提示会移除当前联合块的状态部分，任务、原文与验证证据保留。

归档记录标明 `view=brief/detail`。原文恢复仍使用已有 `recall({from,to})`；`recall({id})` 读取该记录保存的资料。

## 后台任务

| 调用方式 | 行为 |
| --- | --- |
| 直接调用 Shell，省略 `run_in_background` | 最多先等 10 秒，仍未结束则返回同一命令的 job id，原超时继续计时。`yieldMs` 可设为 250–30000 毫秒。 |
| `run_in_background: false` | 完整等待前台结果。 |
| `run_in_background: true` | 立即返回 job id，支持读取增量输出；保留原显式后台的超时规则。 |
| `run_code` 内省略后台参数 | `await` 继续等待最终结果，不自动变成 job id。 |

自动让出不会重新执行命令。自动让出的任务在结束后提供捕获结果；需要运行期间的日志时，请显式启动后台任务。停止或卸载运行时会取消并等待其拥有的进程，不会在重启后重跑旧任务。旧编号不会指向重启后新建的任务。

完成通知包含任务编号、结束状态和有界输出预览。预览不消耗显式读取游标；输出不完整时继续调用 `job_output`。完成只表示执行结束，仍须检查退出码、超时、截断和实际结果。

直接调用 `job_output({job_id, wait:true})` 时，省略 `timeout_ms` 会等待事件；任务完成、新插话、其他任务完成或指定超时都能结束等待。返回的 `wakeReason` 分别为 `completed`、`user_input`、`other_completion`、`timeout`。被唤醒不等于目标完成，也不会取消目标任务。

等待期间，输入框的主发送按钮显示“现在发送”，Enter 直接插话；显式排队仍保留。等待结束后恢复原输入偏好。若当前模型步还同时执行其他阻塞工具，需要等那些调用也结束后才能发起下一次模型请求。

## OMD-PTC

开启后台优化后，`job_output`、`job_list`、`job_kill`、`runtime_status` 可以直接调用；其他业务工具继续通过 `run_code`。

```js
return await tools.bash({
  command: "pnpm test",
  description: "Run project tests",
  run_in_background: true
});
```

先返回任务编号，在后续步骤处理独立工作或等待结果。Windows 使用 `tools.pwsh`。PTC 程序内部的等待仍有原有限时，并受整个程序超时约束；本功能不把整段程序自动放到后台。

## Todo 阻塞处理

当没有可执行的有效下一步时，模型可以调用：

```json
{"op":"pause_turn","reason":"缺少服务连接；需要先启动服务才能继续验证。"}
```

这会停止本回合的 Todo 收尾催促，让模型正常说明阻塞。未完成任务、证据和 BT 设置保持原样；新的用户输入或新回合恢复检查。完全相同的收尾提醒在同一回合、同一用户输入范围内只投递一次。

它不停止后台进程，也不暂停独立的 Goal。需要停止进程时仍调用 `job_kill`。

## 配套运行时

发行包包含基于 DSH 0.1.6-alpha.2 的匹配组件，通过插件配置加载。宿主原工具注册表、Jobs、Shell 和输入框组件的完整实现保留，只增加上述能力。原生 DSH 预设保留原有执行方式；卸载 OMD 后原组件恢复，无需手工修改 `node_modules`。

在插件管理中启停整个 OMD 时，页面会自动刷新以切换完整输入框组件，会话历史、设置和文字草稿保留。附件需要重新添加；实验性功能开关本身不会刷新页面。

运行状态和预览增加少量上下文；状态与任务联合更新时会再次携带任务列表。没有新增总结模型调用，也不承诺对所有模型和任务都有同样收益。
