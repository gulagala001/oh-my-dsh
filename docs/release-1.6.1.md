# Oh My DSH 1.6.1 正式版

兼容 DSH 0.1.6-alpha.2，内置 OpenCU 1.0.4 的更新快照。插件 ID `trisoul_x`、Agent preset `trisoul-x` 和已有数据目录保持不变。

## 更新内容

- 执行中的操作抽屉持续显示最新动作，优先复用调用说明，否则显示工具名称和关键参数；工具返回后等待模型继续时仍保留，整轮结束后恢复简写汇总。
- Job、list_agents 等通用工具调用，以及普通上下文、Todo／运行状态记录统一收进抽屉；上下文压缩保持独立显示。
- 展开可查看原始参数、结果、失败和停止状态，保留已打开的详情；刷新后按实际回合状态恢复展示。
- 操作抽屉滚动到边缘后可继续滚动外层对话，Computer Use 悬浮预览支持从内容区域拖动。
- 上下文后台短重试耗尽后，可在主会话请求恢复成功时自动重试一次；保留退避、并发限制和手动重试。

## 安装与升级

停止原服务，沿用原来的 `DSH_HOME`、profile、模型配置和凭据安装：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v1.6.1
```

自定义 profile 请将 `web` 替换为原名称。随后按原方式启动 DSH 并刷新页面。插件安装不会升级全局 DSH。

左上角版本入口会在成功检查发布清单后，对较旧正式版显示普通更新提示，并列出本次说明；可点击“检查更新”立即检查。此入口不自动安装。

发行资产包含 `.tgz` 安装包、含已构建界面的源码 ZIP 和 SHA-256 校验清单；不包含本地会话、凭据和内部交接记录。
