# 在对话里使用电脑与浏览器

[首页](../README.md#computer-use) · [安装条件](install.md) · [完整文档](README.md)

OMD 0.99.1 源码默认内置 OpenCU `2.0.7`。独立安装与内置共装复用同一套核心和工具，不需要再启动控制服务，也没有单独的 CU 控制台。

## 第一次使用

1. 确认插件与宿主完整版本匹配，完整内置浏览器与原生监看所需的 Host／Client／preload 适配已安装。
2. 打开 **设置 → 电脑与浏览器**。检查后端状态，按需要安装匹配的 Playwright 浏览器资源或准备系统权限。
3. 想用已有 Chrome／Edge profile 时安装扩展，在首次连接提示中选择 **允许并记住**。只配对你希望使用的 profile。
4. 用无敏感内容的小任务开始，例如：“打开这个页面，搜索 release notes，告诉我看到了什么。”

模型需要工具调用能力；理解截图还需要图像输入。OS 权限与逐应用访问授权分别生效，不自动授权或提权。

## 你在界面里做什么

- **查看现场**：普通电脑操作带出页面、活动和监看。点击预览回到对应目标；隐藏预览不等于停止任务。
- **留下批注**：在网页具体位置、图片或支持的内容上评论。回复正文也可选中文字批注。保存与提交分开；明确提交后才加入对应对话草稿。
- **自己操作**：人工活动通知让 AI 重新观察，不要求强制“接管／恢复”。
- **停止任务**：明确停止会取消并释放 AI 记录的键鼠输入；发生错误会保留诊断，不清空状态假装成功。

## 目标切换、取消与恢复

目标按实际浏览器、标签或窗口身份绑定；同名窗口和关闭后重开的标签不会自动冒充原目标。页面变化后重新观察，人工操作后核对现场再继续。

停止、超时或会话退出会等待相关输入的释放回执；释放失败保留状态，允许再次明确停止。目标清单、选择和扩展读取支持取消，旧读取的迟到结果不会恢复已取消的操作，也不会停止另一个会话拥有的目标。授权等待超时与后端读取超时分别报告，便于定位问题。

监看目标和操作目标可以不同。浮动预览支持多个目标，隐藏、切换或重开后核对实际目标；批注只在明确提交后进入草稿。

## 浏览器路径

| 路径 | 条件 |
| --- | --- |
| DSH 内置浏览器 | 配套桌面 Host 与 OpenCU 客户端／preload。 |
| 托管 Chromium | 匹配 Playwright 浏览器资源，使用独立浏览环境。 |
| Chrome／Edge 扩展 | 本机 bridge 与初次配对；保留身份和数据的正常重启可恢复。 |

绑定目标不主动激活窗口，输入默认后台。目标不支持后台操作时返回 `FOREGROUND_REQUIRED` 或具体限制；需要用户同意后明确聚焦与前台输入，不偷偷退回全局键鼠。

## 当前边界

- macOS 使用系统无障碍接口、窗口截图和定向事件；应用可能忽略后台事件，键盘受应用内部键盘窗口约束。
- Windows 使用 UIA／Win32，Linux 使用 X11／AT-SPI 或 Wayland portal；可用操作取决于系统依赖、权限和应用支持。Wayland 共享显示器不等于独占某个应用截图。
- 多屏混合缩放不在当前支持范围。
- 动作回执说明派发状态，实际结果需重新观察。
- 本地数据按配置的 `dataDir` 保存，未配置时使用 `DSH_HOME/opencu` 或 `~/.opencu`。下载历史清理不删除已交付文件。
