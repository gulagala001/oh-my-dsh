# 0.2.0

OMD 从本版开始使用独立版本编号，完整承接 [0.1.7-rc.2.20](release-0.1.7-rc.2.20.md) 的 Dream 记忆、右侧工作台、界面交互、离线安装及结构简化成果。本次同步版本、发行说明、安装入口和官网，产品运行实现保持不变。

本版仍配对 **DSH 0.1.7-rc.2**，内置 **OpenCU 1.1.8**。OMD 与 DSH 的版本独立；OMD 0.2.0 不代表已适配 DSH 0.2。已有模型、会话、附件、外观、插件配置和历史回查继续保留。

## 升级

先结束运行任务并备份实际 DSH 数据目录，在原 profile 安装 `github:gulagala001/oh-my-dsh#v0.2.0`，完整退出并重启宿主，再确认当前插件版本为 0.2.0。桌面通过应用内插件管理器安装，详见[升级指南](upgrade.md)。旧标签及安装包保留，使用本次 0.2.0 作为新的安装入口。

## 验证

本次核对版本排序与旧版更新识别、包与前端版本、文档链接、构建和隔离安装。未变化的产品实现沿用前版的跨平台、宿主、OpenCU 与实际安装证据，具体提交、包校验值、本次检查和未覆盖范围见 [Release](https://github.com/gulagala001/oh-my-dsh/releases/tag/v0.2.0) 的 `verification.log`。

## 已知范围

前版记录的 Windows 首次导航超时、一次模型截图工具失败，以及 macOS 工作台重开后的即时命中失败仍保留；后续通过不代表这些偶发失败已定位或修复。前版合并后的 Windows CI 还记录了测试准备阶段的连接重置及清理临时目录时的 EPERM；这两项不计为通过，也不因更改版本号而宣称解决。

DSH 0.2 的独立适配、真实模型全矩阵、长期压力、WSL 真机与多屏混合缩放不在本次版本调整的验证范围内。
