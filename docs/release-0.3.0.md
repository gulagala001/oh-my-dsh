# Oh My DSH 0.3.0

配对 **DSH 0.2.0-rc.2**，内置 **OpenCU 1.2.0**。仍使用 DSH 0.1.7-rc.2 的用户请留在 OMD 0.2.2；本次需要同时升级宿主，不能只换插件。

## 改动

SDK、原生工具/会话组件、Conversation 和共享 Chat 快照统一到官方 `dsh-v0.2.0-rc.2`，提交 `639ed015397290b3745d163aafe02ffee4aa3f84`。不再用此前的 master 准备快照覆盖新版宿主组件。

合并新版分组文字动画，保留操作计数、失败与中断提示、紧凑布局和展开状态。现有上下文处理、Dream、Todo/验证、原话与附件、Trace、PTC/工作流、模型设置、电脑操控、主题和配色的设计不变。

同步官方 macOS arm64、Windows x64 rc.2 桌面包的文件大小与 SHA-512，下载验证仍拒绝元数据或校验不符的包。源码和离线依赖使用官方 npm 发行包；不再保留开发期间为上游缺包建立的临时归档或覆盖。

推荐的需求理解组件更新至独立版本 0.2.0，仍然默认不安装、安装后默认关闭。已有用户需同时更新这个独立组件；旧版 0.1.0 继续用于 DSH 0.1.7-rc.2。第三方插件也应先升级至各自支持 rc.2 的版本，不能通过跳过兼容检查替代适配。

## 安装

官方桌面在应用内安装 OMD，随后完整重启。Web 和源码使用[安装指南](upgrade.md)中的固定版本命令，保留原 DSH_HOME、profile 和端口。OMD 用户无需重复安装 OpenCU。

## 升级与回退

先结束任务、停止原服务或完整退出应用，备份实际 DSH_HOME。保留模型渠道、凭据、原 profile、端口、外观和历史数据。重启后检查实际宿主 `0.2.0-rc.2` 和插件 `0.3.0`。回退使用旧程序与完整备份副本，避免新旧宿主交替写同一目录。
