# Oh My DSH 0.3.0

配对 **DSH 0.2.0-rc.2**，内置 **OpenCU 1.2.0**。仍使用 DSH 0.1.7-rc.2 的用户请留在 OMD 0.2.2；本次需要同时升级宿主，不能只换插件。

## 改动

SDK、原生工具/会话组件、Conversation 和共享 Chat 快照统一到官方 `dsh-v0.2.0-rc.2`，提交 `639ed015397290b3745d163aafe02ffee4aa3f84`。不再用此前的 master 准备快照覆盖新版宿主组件。

合并新版分组文字动画，保留操作计数、失败与中断提示、紧凑布局和展开状态。现有上下文处理、Dream、Todo/验证、原话与附件、Trace、PTC/工作流、模型设置、电脑操控、主题和配色的设计不变。

同步官方 macOS arm64、Windows x64 rc.2 桌面包的文件大小与 SHA-512，下载验证仍拒绝元数据或校验不符的包。

## npm 缺包与安装

上游 `dsh-web-app@0.2.0-rc.2` 引用了尚未发布的同版本账号设置包。开发/离线安装通过官方同标签的未修改包源码构建补齐，保留来源、SHA-256 和 MIT 许可；没有混用 rc.1，不挂载第二套账号组件，也不修改官方桌面的账号实现。

官方桌面直接在应用内安装 OMD。Web 使用[安装指南](upgrade.md)中的锁定源码宿主，不使用已知会缺包的全局/npm 命令覆盖旧安装。补齐归档位于 OpenCU 快照的 `vendor/dsh-sdk`，上游补发后可与 override 一同移除。

## 验证

本地通过官方 rc.2 源码完整构建、适配后 Chat/Conversation 类型检查、OMD 构建，以及 29 项真实宿主/界面/工具回归；覆盖原版安装、模式切换、持久化与 fork、原话/图片恢复、模型面板、预算、PTC、工作流和电脑操控。

官方 macOS rc.2 安装回归通过，覆盖安装、重启、会话保留、主题/壁纸、工具执行和卸载恢复。各平台完整测试与最终发行校验以 Release 附带的验证记录为准；不把未执行的平台、真实模型长任务或所有历史迁移组合列为已验收。

## 升级与回退

先结束任务、停止原服务或完整退出应用，备份实际 DSH_HOME。保留模型渠道、凭据、原 profile、端口、外观和历史数据。重启后检查实际宿主 `0.2.0-rc.2` 和插件 `0.3.0`。回退使用旧程序与完整备份副本，避免新旧宿主交替写同一目录。
