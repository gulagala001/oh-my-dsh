# 0.2.0-rc.2.omd.0.6.0：Pro、工作流恢复与同轮侧问

本版配对官方 DSH `0.2.0-rc.2`，OMD 功能版本由 `0.5.2` 升至 `0.6.0`。

## 双宿主安装

| 使用环境 | DSH 宿主 | OMD 版本 |
| --- | --- | --- |
| 现有官方桌面 | `0.2.0-rc.2` | `0.2.0-rc.2.omd.0.6.0` |
| Web／源码 | `0.2.1-alpha.1` | `0.2.1-alpha.1.omd.0.6.0` |

按实际宿主安装对应完整版本，不把 alpha.1 插件装入 rc.2 桌面。本次不升级官方宿主；内置 OpenCU 保持 `1.2.1`。升级前结束任务、停止服务或完整退出应用，并备份实际 `DSH_HOME`。

安装来源：`github:gulagala001/oh-my-dsh#v0.2.0-rc.2.omd.0.6.0`。另一宿主见[对应发行说明](release-0.2.1-alpha.1.omd.0.6.0.md)，完整步骤见[安装与升级指南](upgrade.md)。

## 本版改动

- 新增 **Pro**：使用模型支持的最高推理档，保留需求拆分、子代理实现与迭代，不增加额外验证编排。模型滑条依次为原生档、Pro、Ultracode；Pro 的蓝色渐变、粒子和光晕更克制，Ultracode 保留强化验证与原有特效。切模型保持所选模式；恢复默认或回到原生档关闭模式。
- 工作流支持部分步骤失败后保留可用结果、定位具体错误、从缓存恢复，并显示取消原因。
- Computer Use 的 `timeoutMs` 支持 **1–300000 毫秒**，改善超时后的恢复、重复调用说明与设备模拟。
- `/btw` 可在主回合同轮侧问，复用最近已发出请求的上下文，答案在对话中显示。
- CommandCode Responses 按最后一条真实用户消息划分图片范围，只发送该回合及其后工具结果的图片；历史文字和原图日志保留。仅作用于 `cmdgoat-responses` 且目标域名为 `api.commandcode.ai` 的配置。

- 局部简化：五处模型请求适配共用同一套挂载与卸载逻辑，保留各渠道政策；Pro／Ultracode 参考状态集中维护，粒子动画由 CSS 统一控制。
- 日常 CI：完整通用回归只在 Linux / Node 24 运行一次并分片；Node 22 与 Windows 分别保留兼容契约和平台重点检查。离线、官方桌面专项各自负责实际安装，过期 PR 自动取消，合并后不重复跑同树测试；手动完整矩阵保留。

## 验证与范围

本轮本地已确认 native／PTC 调用、真实浏览器交互、隔离安装及恢复检查。Pro 的键盘选择、切模型保持、默认复位、明暗与窄屏布局、减少动画，以及工作流的错误与恢复均有针对性检查。双宿主发行包与跨平台 CI 的最终结果由对应发布记录补充。

本版未宣称三个历史 HTTP 400 问题全部修复；CommandCode 改动仅覆盖上述历史图片投影范围。本轮未重新完成 Android QQ 和 Windows 的全部实机验收。
