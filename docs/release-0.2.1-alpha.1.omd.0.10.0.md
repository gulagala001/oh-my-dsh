# OMD 0.2.1-alpha.1.omd.0.10.0

本发行配对官方 DSH 0.2.1-alpha.1，沿用该宿主对应的 SDK、原生组件与依赖锁定。

原版异步仍为默认。工作台 → 上下文 → 异步压缩可切换主动异步，按会话保存。独立后台请求沿用当前主请求前缀，让模型判断是否整理；主对话继续，结果在安全边界应用。用户要求或模型路由变化时，过期自动方案作废，原文及已有摘要保留。

recall({search: "original", query: "关键词"}) 搜索当前会话原始正文和工具输出，返回有界片段、事件位置及续页游标。跨会话须显式 sessionId；不建立另一份历史缓存。原话、附件、档案与事务恢复继续使用既有机制。

后台调用仍产生用量；真实缓存收益未实测。实际验证范围以发行附带 verification.json 为准；Web 不替代官方桌面、Windows/Linux 原生交互或真实供应商模型效果。
