# Oh My DSH 0.1.7-rc.2.2

适配 **DSH 0.1.7-rc.2** 的插件修复版。版本号末尾 `.2` 是 OMD 补丁号；不升级或替换 DSH 的版本依赖。本版包含敏感 API 认证修复，更新提示标记为重要修复。

## 变化

- 同步包含官方预设槽位修复（#13）：恢复原生选择器和已开始会话的只读标签，不增加替代选择器。

- 包含本轮补充修复：空用户占位不再导致后续请求持续报 `400: user message must have content`；发送前修复旧占位，保留原始日志与回查资料。
- Windows 迁移的动态原生依赖通过宿主解析器加载，避免 `koffi` 从插件错误位置解析失败。

- 修复 Web 在模型思考时，标签页标题在 Oh My DSH 和 DeepSeek Harness 之间快速切换（#12）。产品后缀在宿主写入时转换，不再使用观察器反复改回；会话标题和其他正常标题变化仍由宿主决定。
- 自定义敏感 API 在读取会话、正文或启动任务前复用官方 Connection 校验；缺少认证服务时不放行。未知会话查询不再分配持久状态。
- JSON 请求先按字节收齐，再统一解码，避免中文或 emoji 跨网络块时损坏；超限和读取超时明确拒绝。
- 保留宽范围旧 V0 会话迁移，支持早期权限来源、TriSoul 推理及任务附加字段、旧 replayState、子会话与压缩记录。保留原始日志和关联备份，迁移后的新副本仍严格验证，不扩大权限。
- 长会话的多记录检查共享本轮位置索引，结束会话在后台工作收敛后释放无主缓存；完全相同的状态保存不重复刷盘，关键变化仍保留原有持久化边界。
- 不相关历史档案损坏时保留健康结果，并明确显示结果不完整；当前会话的损坏和事务恢复仍严格处理。
- 项目摘要根据所选模型的可用容量保守注入；未注入部分不标记为已发送，也不删除。现有目录与 `recall` 提供续页，完整文档仍按编号读取。
- 推荐插件区分操作中的临时目录警告与最终失败，继续使用官方安装、取消、卸载及权限机制。组件页首次读取失败可见错误并重试，轮询复用已有实现。

没有新增通用诊断平台、第二套 token 账本、评测平台或存储框架；现有 Todo、原话附件、Trace、电脑操控和项目/会话隔离保留。

## 升级

先等任务结束，停止服务或完整退出桌面应用，完整备份实际 `DSH_HOME`，再安装本版。宽范围迁移会为受支持的旧日志生成新格式副本；不要删除旧代际和恢复记录。旧宿主不保证能读取新代际，回退应恢复升级前备份，而不是手工编辑日志。

Web 沿用原 profile、数据目录和端口，将插件来源更新为 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.2`。也可安装 Release 中的 `trisoul_x-0.1.7-rc.2.2.tgz`，用同页 `SHA256SUMS` 核对。

官方桌面版使用其自身的 `desktop` profile：从应用内插件页更新，完成后完整退出并重开。不要用普通 CLI 管理桌面 profile，也不要把 Web 的已安装状态当成桌面已更新。
