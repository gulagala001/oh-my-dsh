# OMD 0.15.1 本地兼容修复

配对 DSH **0.2.1-alpha.2**，保留 0.15.0 的完整增强与 OpenCU 1.6.0。本候选未正式发布，不替换正在使用的实例。

此前停用 OMD、冷重启宿主后再次启用，会遇到原生文件上传解析器重复注册，导致会话服务无法恢复。兼容层现在识别原生控制器的卸载阶段，等待失败构造的异步清理完成，仅恢复已识别的原生注册错误；未知回调、其他插件的有效注册和已经退役的作用域保持原有边界。

原生回调识别按已核对的宿主 SDK 固定；宿主实现变化时保守保留未知注册，不据此推断新版本兼容。具体运行证据与 IUI 1.7.0 的两种安装顺序、启停、重启、卸载及状态恢复结果随本地构建交付。macOS Web 验收不外推为 Windows、Linux 或官方桌面通过。
