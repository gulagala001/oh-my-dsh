# 0.1.6-alpha.2.2

适配 **DSH 0.1.6-alpha.2**，继续使用 DSH 的模型、会话、权限、工具循环和原文日志。

- **运行状态**：与 Todo 合并投递时间、上下文估算、记录表示和后台任务事实；默认关闭。
- **后台优化**：长命令自动让出、完成输出预览、事件等待与插话；默认关闭。
- **OMD-PTC**：完整 OMD 预设；开启后台优化后，可直接等待、读取或取消后台任务。
- **Todo**：遇到阻塞可暂停本回合催促，保留未完成项；重复提醒不再无限触发。
- **基础组件**：CodeGraph 和 Computer Use 默认启用并自动准备；统一状态、开关和重试入口。内置 OpenCU 1.0.4。
- **实验设置**：CoT 前置、CFR、状态提示与后台优化集中管理；已有会话在下一次请求使用新设置。

## 升级

停止服务，使用原来的 `DSH_HOME` 和 profile 安装，然后按原方式启动：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v0.1.6-alpha.2.2
dsh web
```

无需清空会话、记忆、索引或浏览器配置。已经明确关闭的组件保持关闭；实验项不会自动打开。

通过插件管理启停整个 OMD 会自动刷新页面，并恢复原宿主或 OMD 输入框；文字草稿保留，未发送附件需重新添加。普通实验开关不触发刷新。

## 验证范围与限制

验证覆盖真实 DSH 加载和模型请求、普通预设共存、OMD/PTC 切换、命令只执行一次、插话、输出读取、压缩回放、设置界面、安装重启和卸载。脚本化模型用于验证执行契约，不作为模型能力提升的 A/B 证据。

首次下载依赖需要网络。macOS 原生桌面助手需要 Apple Command Line Tools，Windows 构建原生组件需要 .NET 10 SDK；系统权限和首次 Chrome 扩展加载仍需用户操作。单机自动测试不替代其他设备上的系统授权和真实应用验收。

本版不支持整段 `run_code` 自动后台化，也不自动重启旧进程。后台自动让出的第一版在结束后提供捕获输出；运行中增量日志使用显式后台模式。

源码和安装包提供 SHA-256 校验；配套 DSH 源码基线、补丁及构建说明见 [vendor/dsh](../vendor/dsh/README.md)。
