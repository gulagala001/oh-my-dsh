- “查看发布记录”固定打开完整发布列表，不再根据本地版本跳转到旧 tag。
- 有新版时保留独立的“查看新版说明”；离线或已经是最新版时，发布记录入口也始终可用。
- 继续包含 0.1.7-rc.2.5 的面板内更新、安装进度、失败重试、待重启提示和运行状态行抖动修复。

## 升级

0.1.7-rc.2.5 用户可在版本面板检查更新后点击“更新”。更早版本通过 DSH 应用内“插件”或原 Web 安装方式安装：

```text
github:gulagala001/oh-my-dsh#v0.1.7-rc.2.6
```

安装后完整重启 DSH，再确认“当前版本”为 **0.1.7-rc.2.6**。
