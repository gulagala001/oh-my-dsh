# Oh My DSH 0.1.7-rc.2.12

正式修复版，适配 DSH 0.1.7-rc.2 Web 与官方桌面，内置 OpenCU 1.1.6。

## 修复桌面壁纸显示

官方桌面与 Web 构建的布局类名不同。上一版虽然保存了壁纸和显示区域，但桌面会话区仍保留实色底层，部分区域找不到挂载目标，导致壁纸只在左侧明显可见。

本版通过宿主的稳定结构标记识别侧栏、会话区和工作台，修复「整个界面」「仅会话区」「仅左侧栏」的实际显示，并让侧栏与会话区统一应用面板不透明度。默认主题未选择额外配色时，不透明度也正确生效。原有图片、主题、配色与高级设置保留。

在 **设置 → 外观 → 自定义背景** 选择区域；面板不透明度越低，壁纸越明显，文字不随之变淡。

## 升级

通过应用内版本面板更新，或在原生插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.12`。完整退出并重新打开桌面，确认「当前版本」为 0.1.7-rc.2.12。

## 验证

新增官方桌面浅色／深色、三个壁纸区域的截图像素对比，修复前准确复现会话区像素完全不变的缺陷；同时检查重启保留和卸载清理。Web 回归覆盖五种布局、两个明暗模式、三个区域，另检查默认配色的不透明度和高级分区外观。实测结果见发行附件 `verification.log`。
