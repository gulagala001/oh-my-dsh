# Oh My DSH 0.1.7-rc.2.14

适配 DSH 0.1.7-rc.2 Web 与官方桌面，内置 OpenCU 1.1.7。本版集中修复安装、设置保存、会话切换和错误恢复，并完善 GitHub 安装与使用文档。

## 安装与交互修复

- 源码目录移动后，`pnpm start` 自动修正指向旧目录的 `link:`，保留已有发行包安装来源。
- 推荐插件安装或卸载失败时，错误保留到重试，不再被后台刷新清除；服务停止后不继续提交待执行的卸载，执行前重新检查并发操作和管理权限。
- 桌面界面与后端版本不一致时，提示完整退出或重启应用与 Host；操作前先等当前任务结束。
- 上下文操作错误不会被轮询清除，切换会话后忽略过期操作和资料读取结果。会话范围的迟到读取不再覆盖新选择，上一会话的保存也不会锁住下一会话。
- 全局背景保存冲突时保留草稿，可读取另一窗口的最新内容、比较并合并；保存时继续检查版本，防止覆盖后续修改。
- 基础组件路径只提交已编辑的字段；保存期间继续输入的内容会保留，并提示再次保存。

## 文档与反馈入口

新增[文档目录](README.md)、[首次使用](getting-started.md)和[排障指南](troubleshooting.md)，将桌面、Web 与源码安装流程分开说明。Windows 命令固定宿主版本，无需先全局安装 DSH。GitHub 增加 Bug、功能建议和 PR 模板；贡献指南说明开发、文档核对和验证流程。文档检查会核对安装版本、徽章、内置组件及本地章节链接。

## 升级

在版本面板更新，或在原生插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.14`。Web 用户重启原 DSH 服务；桌面用户完整退出并重启应用与 Host，确认“当前版本”为 0.1.7-rc.2.14。已有 Oh My DSH 用户无需另外安装 OpenCU。

保留 `.13` 的 WSL Windows 桌面桥接，配置步骤见 [WSL 指南](windows.md#wsl-控制-windows-桌面)。发行包不含预编译 Windows 桌面程序。

## 验证

本地 macOS 已验证官方桌面发行包安装、版本不一致时的重启提示、会话与主题保留、浏览器工具调用及卸载后恢复原生界面。文档检查覆盖版本配对和本地章节链接，发行包检查确认内置 OpenCU 快照完整且不含本地交接资料或配置。

Windows／WSL 真机的截图、输入、停止、缩放及进程清理不在本轮本地验收范围；自动测试和只读连接自检不能替代这些检查。
