# 0.1.6-alpha.2.3 · 必要更新

修正运行状态注入频率。旧版检查更新时显示红色必要更新标记，安装后解除。

- 状态随真实新用户输入、开启状态、Todo 正常投递、压缩刷新或提示块缺失补回而更新。
- 没有 Todo 时仍能提供状态，不自动创建任务。
- 后台任务、上下文记录内部变化、自动新回合、模型切换、时间和 token 数值变化不单独触发，避免重复注入。
- 压缩刷新后不重复追加；日常尾部追加和压缩时清理旧快照的规则保留。

运行状态和 CFR 默认关闭，后台优化与 CoT 前置默认开启；已有设置不重置。状态查询、任务账本、验证证据和历史原文保持原有行为。详见[运行状态说明](runtime-state-background.md)。

## 安装与升级

适配 DSH 0.1.6-alpha.2，继续内置 OpenCU 1.0.4。停止服务后使用原 profile 安装，沿用原 `DSH_HOME`、模型配置和凭据：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v0.1.6-alpha.2.3
```

## 验证范围与限制

验证包含状态触发去重、真实新输入与历史重写、压缩和回放，以及两个 OMD 预设的实际宿主请求。后台任务从启动到结束不新增状态块，真实插话刷新一次。

本次不修改 Computer Use 或后台执行实现，其平台和执行边界沿用[上一版说明](release-0.1.6-alpha.2.2.md#验证范围与限制)。这些验证不构成真实模型能力收益的 A/B 结论。
