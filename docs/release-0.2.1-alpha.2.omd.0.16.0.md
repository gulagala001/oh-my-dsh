# OMD 0.16.0 整合候选：Dream 范围、监控与原生恢复

本候选未正式发布，配对 DSH **0.2.1-alpha.2**，内置 **OpenCU 1.6.1**。本次整合源码，不更新现有 Web 或桌面部署；旧宿主继续使用各自 SDK 与组件的独立构建。

Dream 的自动整理设置可选择要整理的工作区文件夹；空选择沿用全部项目。工作区来自宿主公共注册服务，界面分组与后台执行使用同一归属规则，嵌套项目不会跨到另一已展示分组。缺失目录保留历史入口，不因此删除记忆或撤回已有贡献。

单个目标暂时失败时，其余会话继续整理；作业保留失败态、已完成进度、未完成目标及首次来源截点。手动重试或进程重启后继续原范围，父记忆等下层完整后再更新。独立 Chat、退出共享和失效父记忆的隔离规则保持生效。

监控整合更紧凑的概览布局、筛选弹层、上下文和资源展示，支持键盘、减少动态效果与原生调用身份。修复未选择会话时全局设置与 Dream 自动设置读取失败。插件重新启用时恢复已失效的原生文件上传解析器，保留第三方有效回调、活跃控制器和正常卸载生命周期。

OpenCU 1.6.1 保留完整的停止、人工接管、恢复、多目标、批注、下载和小窗能力。开始页直接打开宿主浏览器，有实际网页或应用目标时打开对应内容，旧无目标标签迁移保留原焦点。

macOS 上的最终整合检查通过：112 项后端回归、8 个原生会话基线、真实 Web 会话生命周期、5 项 CU 集成与下载交付、Dream 嵌套范围与保存交互、监控和原生工作台交互、两种插件加载顺序的上传／启停／重启／卸载，以及 11 项文档检查。发行包未包含工程内部资料，内置 OpenCU 296 个文件与固定快照清单一致。

验证结论绑定本候选源码、安装包与真实宿主执行。主分支已有其他宿主 API 迁移相关的全量 CI 失败，本次针对性通过不代表全量 CI 通过；Windows、Linux 与官方桌面未在本次重新验收。受控模型与隔离 Web 结果不证明真实供应商效果。
