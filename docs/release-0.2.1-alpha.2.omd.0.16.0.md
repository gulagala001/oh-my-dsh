# OMD 0.16.0 本地交付候选：Dream、监控与 OpenCU

本候选尚未公开发布。当前源码版本为 **0.2.1-alpha.2.omd.0.16.0**，配对 DSH **0.2.1-alpha.2**，内置 **OpenCU 1.6.1**；正式桌面 **DSH 0.2.0-rc.2** 使用其对应 SDK、组件快照和依赖锁文件的单独构建，不更换宿主。相对已部署的 0.15.0，本版为功能升级，保留 0.16.0 编号。

上下文、Dream、Pro／工作流、监控与外观的整合已进入主分支，本轮继续纳入电脑操作界面和 OpenCU 更新。源码已合并与公开发行是不同状态；本版没有公开 tag、Release 或市场收录结论。

## 长任务与工作台

Dream 的自动整理设置可选择要整理的工作区文件夹；空选择沿用全部项目。工作区来自宿主公共注册服务，界面分组与后台执行使用同一归属规则，嵌套项目不会跨到另一已展示分组。缺失目录保留历史入口，不因此删除记忆或撤回已有贡献。

单个目标暂时失败时，其余会话继续整理；作业保留失败态、已完成进度、未完成目标及首次来源截点。手动重试或进程重启后继续原范围，父记忆等下层完整后再更新。独立 Chat、退出共享和失效父记忆的隔离规则保持生效。

监控整合更紧凑的概览布局、筛选弹层、上下文和资源展示，支持键盘、减少动态效果与原生调用身份。修复未选择会话时全局设置与 Dream 自动设置读取失败。插件重新启用时恢复已失效的原生文件上传解析器，保留第三方有效回调、活跃控制器和正常卸载生命周期。

## OpenCU 与安装

OpenCU 1.6.1 使用插件自有的真实浏览器，接入宿主统一标签栏，保留分栏、侧栏、操作预览、停止、人工接管、恢复、多目标、批注、持久下载和小窗。实际网页或应用目标在对应内容中打开，DSH 原生浏览器入口继续保留。下载文件在原生与 OMD-PTC 会话中保留为可预览附件，停止控制或重启服务后仍可读取。

- **OMD 集成安装**：安装与 DSH 版本匹配的 OMD 构建，使用内置 OpenCU 及完整 OMD 工作台。
- **OpenCU 独立安装**：使用 [OpenCU 仓库](https://github.com/gulagala001/opencu)提供的版本匹配构建，在原生 DSH 中使用相同电脑操作能力。
- **两者共装**：共享一套服务、工具、入口、运行环境和数据；卸载其中一个后保留另一份能力。

首次安装准备插件自有运行时，下载官方预编译 **Electron 44.7.0**，不编译 Electron 或 Chromium，也不替换 DSH 桌面宿主。准备失败时，在 OMD 插件目录运行 `pnpm prepare:computer-use` 重试。原生桌面组件、Chrome 扩展和系统权限按当前平台在「运行环境与权限」中设置；浏览器数据保留操作系统加密与用户授权，不导入受保护的系统数据。

本地候选尚无公开固定安装入口。公开 tag 安装仍使用各自发行说明，本地 alpha.2 包不能直接用于 rc.2 桌面。

## 验证边界

此前 macOS alpha.2 隔离 Web 已验证 Dream 范围、监控、原生工作台、插件生命周期和 OpenCU 下载交付。该结果绑定当时的源码与构建，不能替代本轮新增 OpenCU、共装与 rc.2 桌面的统一验收。

本轮统一运行结论尚待完成。Windows 未实机验证；Linux、全部第三方插件版本、真实供应商模型与真实账号全业务均未据此宣称通过。平台运行条件、自动化回归和隔离 Web 结果不能替代相应设备上的实际使用验证。
