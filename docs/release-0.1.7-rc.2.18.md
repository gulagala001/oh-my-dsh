# OMD 0.1.7-rc.2.18

本版配套 DSH 0.1.7-rc.2，继续内置 OpenCU 1.1.7。

修复后台 Workflow 卡片误显示“已中断”的问题。此前，启动工作流的工具步骤结束后，卡片会把仍在后台运行的工作流和子智能体标成中断，并禁用成员入口。现在卡片根据对应原生 Job 的运行状态显示进度，主回合结束和页面刷新后仍可进入运行中的子智能体。

修复只校正有明确后台任务依据的推断状态。实际完成、取消、失败，以及宿主重启后已不存在的任务，继续按真实记录显示；原有执行、权限和取消机制保持不变。

## 升级

对应 Release 发布后，等待当前任务结束，在 OMD 版本面板更新到 `0.1.7-rc.2.18`，然后完整退出应用与 Host 并重新打开。桌面使用原生插件管理器，不使用 CLI 修改 `desktop` profile。升级保留模型、会话、Ultracode、外观和其他插件配置。
