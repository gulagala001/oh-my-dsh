# 0.1.7-rc.2.5：面板内更新与运行状态稳定性

配套 **DSH 0.1.7-rc.2**，内置 OpenCU 版本保持 **1.1.4**。

## 变化

- 保留左上角品牌旁的版本图标。检查到新版本后，在点开的面板内显示“更新”按钮，点击即可由 DSH 原生插件管理器安装。
- 显示安装进度、失败原因、重试和待重启状态。关闭面板后安装继续；重复点击不会启动多次安装。有任务运行时提示等待，版本不兼容时保留宿主诊断。
- 更新接口使用宿主认证与来源校验，仅安装官方发布清单中的目标版本。“查看新版说明”打开检测到的版本。
- 修复运行状态文字长短变化时，右侧操作数和失败数被挤压换行导致的抖动；长文字省略显示，数量保持单行。

## 升级

**0.1.7-rc.2.4 及更早版本尚无面板内更新按钮，首次升级仍需通过原安装入口。** 等任务结束并备份实际 `DSH_HOME`，桌面版在应用内“插件”安装以下来源，随后完整退出应用再打开，或使用“重启应用与 Host”：

```text
github:gulagala001/oh-my-dsh#v0.1.7-rc.2.5
```

Web 版沿用原数据目录和 profile，通过同一来源更新后按原方式重启服务。重启后确认面板里的“当前版本”为 **0.1.7-rc.2.5**。此后的新版可在版本面板内直接安装；安装完成后仍需重启 DSH 才会运行新版。宿主版本按配对要求另行更新。

## 验证范围

已验证版本判断、固定安装来源、并发去重、失败重试、认证与来源拒绝；在隔离 DSH Web profile 中实际安装并更新完整 OMD 插件，核对磁盘版本与仍在运行的版本。浏览器验证覆盖图标保留、面板重开、待重启状态、子路径、明暗主题与窄屏，并复现和验证运行状态行高稳定性。

桌面品牌容器有浏览器回归覆盖；本轮未进行原生桌面或 Windows 真机复验，不将其列为本版已实测项目。
