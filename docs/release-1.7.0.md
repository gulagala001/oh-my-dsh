# Oh My DSH 1.7.0

融合 DSH 0.1.7-alpha.1，内置 OpenCU 1.1.0，包含预发布后的展开间距修复。

## 更新内容

- 融合原生工作过程、设置、预设、Jobs 和 V4 会话，保留 OMD 上下文整理、任务验证、BT、预算、PTC 与四套皮肤。
- 工具结束后立即显示完成汇总；保留展开的详情，统一“思考”和动作行的间距，缩小展开标题下方的留白。
- 适配新版明暗主题、窄屏布局、子路径部署和提示词优化。
- 迁移旧会话和上下文引用，保留原日志与恢复记录，修复旧压缩元数据、回合归属和系统头顺序。
- 保留后台任务软让出、硬超时和插话唤醒，修复 Computer Use 重置、共同安装及旧依赖缓存问题。
- 清理重复实现、失效测试和过时说明。

## 安装与升级

从旧版宿主升级请先阅读[完整升级教程](https://github.com/gulagala001/oh-my-dsh/blob/main/docs/upgrade.md)。

先停止旧宿主并完整备份 DSH_HOME，将宿主更新至 DSH 0.1.7-alpha.1，再安装：

```sh
dsh plugin --profile web add github:gulagala001/oh-my-dsh#v1.7.0
```

自定义 profile 请将 `web` 替换为原名称，随后按原方式启动。插件不会自动升级全局 DSH；旧宿主 DSH 0.1.6-alpha.2 请继续使用 OMD 1.6.1。

首次启动会生成 V4 会话并迁移关联索引，原日志不覆盖，旧配置导入后保留为 `settings.yaml.imported`。需要回退时，停止新宿主并恢复成套备份，避免新旧宿主交替写入同一目录。

内部插件、预设与数据目录标识保持兼容。源码、安装包和 SHA-256 校验文件见本版本附件。
