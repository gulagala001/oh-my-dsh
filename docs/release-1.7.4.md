# Oh My DSH 1.7.4

> 历史编号版本。后续版本已改用 `DSH 完整版本.插件补丁号`，请从[最新发布](https://github.com/gulagala001/oh-my-dsh/releases/latest)查看当前版本，完整先后顺序见[更新记录](../CHANGELOG.md)。GitHub 同日版本排序可能让此旧编号显示在新版前面。

继续适配 **DSH 0.1.7-rc.2 Web 与官方桌面版**，内置 **OpenCU 1.1.4**。

- 新安装自动迁移本产品的旧 Chrome 连接，备份旧注册，复用已加载的扩展目录。已迁出的实例不会启动后自动抢回连接，手动准备可切回。
- 修复桌面版本机连接程序未进入 Electron 的 Node 运行模式，导致扩展显示 `Native host has exited`。
- 扩展 0.1.6 与新版本机程序支持迁移时自动释放按键、断开旧连接并连接新实例；用户主动断开后不会自动重连。
- 修复 iOS Liquid Glass、Codex Desktop 和 Claude CLI 皮肤收起右栏后残留色块。背景、模糊、阴影、边框及辅助显示覆盖规则只在展开时生效（#8）。
- 合并社区 PR #10，兼容 npm 11/12 的 `npm pack --json` 输出。

## 安装与升级

桌面版在应用内「插件」安装 `github:gulagala001/oh-my-dsh#v1.7.4`，然后使用应用菜单的「重启应用与 Host」。Web 沿用原数据目录和 profile 安装同一 tag。详细步骤见 [安装手册](upgrade.md)。

升级旧 Chrome 扩展后，如尚未连接，在 `chrome://extensions` 重新加载一次 Oh My DSH Computer Use。旧版已运行的扩展和连接进程不会仅因磁盘文件更新就获得新代码；完成这次加载后支持自动迁移重连。迁移无需卸载扩展、删除注册文件或重新选择扩展目录；首次安装扩展仍需 Chrome 的正常加载步骤。

本版不包含尚未发布的旧 V0 会话历史兼容修复，相关状态见安装手册。
