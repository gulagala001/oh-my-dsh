# Oh My DSH 0.1.7-rc.2.8

正式版，适配 DSH 0.1.7-rc.2 Web 与官方桌面版，内置 OpenCU 1.1.5。

## 外观

主题、配色和背景独立选择。主题保留布局、字体、圆角与玻璃材质，配色只改变颜色；默认选项保持原外观。

复用现有黑白灰、冰蓝、暖砂、晴空蓝配色，不依赖第三方配色插件。支持本地 PNG、JPEG、WebP 背景，提供填满或完整显示、模糊、明暗遮罩和面板不透明度。图片仅在当前浏览器保存，不上传服务器。

切换主题不清除独立配色和背景。三者可分别恢复默认，降低特效时暂时隐藏背景。保留明暗模式和旧主题导入格式，修复 Codex 长设置页控件被压缩的问题。

本版继续包含上一版的实时画面推送崩溃修复，不改动记忆、待办、模型或电脑操作链路。

## 升级

在 DSH 插件管理器安装 `github:gulagala001/oh-my-dsh#v0.1.7-rc.2.8`，完成后完整重启 DSH，确认当前版本为 0.1.7-rc.2.8。入口为「设置 → 外观」。

配色和背景属于当前浏览器／站点；Web 与桌面不自动同步，清理站点数据会删除本地背景。具体限制和恢复方法见 [外观说明](skins.md)。

## 验证范围

真实浏览器覆盖全部内置主题与配色组合的浅深色、布局保留、背景持久化、跨标签页同步、损坏图片拒绝和窄屏设置。现有外观回归和官方 macOS 桌面安装、重启、卸载的实际执行结果随发布验证记录提供。

本轮不将 macOS 结果外推为 Windows／Linux 原生桌面实测。完整 CI 由 GitHub Actions 独立运行。
