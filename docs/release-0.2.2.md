# Oh My DSH 0.2.2

本版简化 OMD 与内置 OpenCU 的实现，不减少现有功能。配对 **DSH 0.1.7-rc.2**，内置 **OpenCU 1.1.9**。

## 变化

外观页面共用操作控件；后台模型能力只有一份缓存；Todo、运行提示与旧任务转换只保留一处实现。摘要与 Dream 共用附件传输，中枢单条选择不再经过多记录排序和中间数组，容量计算集中维护。旧会话、原话、附件、归档、事务恢复、Trace、任务证据与各平台控制权继续保留。

OpenCU 共用有界 UTF-8 JSON 读写、请求取消和设置轮询；安装写入不会被更早的状态读取覆盖。修复侧栏菜单提前取得焦点后跳过关闭监听的问题，保留原生弹窗和外部点击的新焦点。清理关联的未使用导入、重复图标生成、失效注释与测试夹具，不增加新的运行框架。

完整合入 0.2.1 与后续主分支的预处理频率、失败补窗和短窗口修复，不恢复已退役的中枢合并执行器。

## 升级

备份实际数据目录，在原安装入口安装 `github:gulagala001/oh-my-dsh#v0.2.2`，完整重启应用与 Host 后确认当前版本。桌面仍使用应用内插件管理器，不用 Web CLI 改写 desktop profile；模型、凭据和已有设置沿用。[升级指南](upgrade.md)。
