# DeepSeek Workbench

[文档目录](README.md) · [使用指南](usage.md)

在 DSH 里用 DeepSeek 网页聊天、临时网页侧栏和 API 开放平台，还能把网页上的历史转成 DSH 会话接着聊。OMD 默认内置并开启，在 **设置 → Oh My DSH → 功能** 里开关。

- 左侧 **DeepSeek 网页聊天** 在主区域打开网页聊天，支持历史、深度思考、联网搜索和附件。
- `/侧栏（网页版）` 在右侧开一个临时网页聊天，关掉时删除这次的官网对话；删除失败时面板保留，可以重试。
- **设置 → 账号** 打开 API 开放平台。网页聊天的登录和 DSH 的平台授权分开管理。
- 网页聊天里点 **在 DSH 中继续**，把能读取的消息和附件转成一个新的 DSH 会话，下一条由你自己发。

| DSH | 能用什么 |
| --- | --- |
| 标准桌面版 | 内嵌网页和读取历史；重启后要重新登录，不能下载官网文件 |
| 打过适配的桌面版 | 全部功能，包括保持登录和下载 |
| 网页版 | 从外部浏览器打开 |

独立版和安装说明见 [dsh-deepseek-workbench](https://github.com/gulagala001/dsh-deepseek-workbench)（[English](https://github.com/gulagala001/dsh-deepseek-workbench/blob/main/README_EN.md)）。
