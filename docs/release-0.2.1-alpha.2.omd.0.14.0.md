# OMD 0.14.0 候选：原生内容标签页与应用预览

本候选未正式发布。当前配对为 DSH **0.2.1-alpha.2**，内置 **OpenCU 1.6.0**；rc.2 与 alpha.1 使用各自 SDK、原生组件快照和锁文件的独立构建。安装方式见[升级指南](upgrade.md#candidate-install)。

左侧导航和对话布局保持现状。右侧工作台改为宿主原生内容标签页：首次打开显示紧凑的开始页，从这里打开工作区文件、终端、应用预览，以及 OMD 的任务与验证、上下文、记忆与 Dream、监控。入口随实际宿主能力显示，第三方插件继续使用原生注册机制。

已访问的 OMD 页面保留阅读展开、选择和滚动位置；未访问页面按需挂载。旧工作台链接迁移到对应内容页，恢复未选中或折叠的旧标签时保留当前焦点和布局。

OpenCU 将操作摘要、截图与交付文件放在对话中；应用预览独立打开，并随查看目标显示标题。预览保留停止、人工接手、恢复、小窗、浏览器导航与下载能力，设置和操作记录按需展开。浏览器控制仍由 OpenCU 提供，宿主原生浏览器入口按实际可用能力保留。

验证结论绑定本轮实际源码、包哈希、宿主与报告。隔离模型与浏览器流程不代表真实模型质量、真实账号或未实测平台；历史候选说明见 [0.13.1](release-0.2.1-alpha.2.omd.0.13.1.md)。
